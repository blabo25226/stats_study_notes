## 再ビルド・検算

このフォルダで次を実行します。

```powershell
python build.py
python verify_math.py
```

- PDFの生成にはLuaLaTeX（`ltjsarticle` 等）が必要です。`build.py` は日本語ファイル名の処理を安定させるため、`93_scratch/sm_mock1_build/` に英数字の名前でコピーし、各冊子を2回コンパイルしてPDFを戻します。
- 検算にはNumPy・SciPy・SymPyを使用します。結果は `検算結果.json` に出力されます。乱数シードは固定しています。
- コンパイルのログやページ画像は `93_scratch/` に保存し、配布用のフォルダに補助ファイルを混在させていません。

今回の作成対象は統計数理のみです。
