# 07_計算機統計学

統計検定1級「統計数理」「統計応用（医薬生物学）」で扱われる、**乱数・シミュレーション・分布の近似・計算による推定**を学ぶ概念ノート集。

この分野では「アルゴリズム名を知っている」だけでは足りない。**不偏性・分散・尤度・条件付き分布・収束性を導出できるか**を優先する。

## 学習の優先度

### 優先度A：過去問に直接関連

1. [[モンテカルロ法]]：不偏性、分散、必要試行回数
2. [[分散減少法]]：別の推定量を作り分散を比較
3. [[マルコフ連鎖の遷移と収束]]：遷移、定常分布、初期値からの収束
4. [[乱数生成と逆変換法]]：一様乱数から目標分布を生成する式の導出
5. [[多重補完法]]：補完内・補完間分散とRubinのルール
6. [[経験分布と密度推定]]：最尤推定とAIC、区分一定密度モデル

### 優先度B：理解を広げる

- [[ニュートン法とFisher_scoring]]、[[非線形方程式の数値解法]]：スコア方程式の反復計算
- [[ブートストラップとジャックナイフ]]、[[置換検定とランダム化検定]]：リサンプリングによる分散・検定の評価
- [[交差検証]]：予測誤差によるモデル選択、線形回帰のLOOCVの閉形式
- [[重点サンプリング]]：珍しい事象と積分の分散減少

### 優先度C：発展事項

- [[MCMC]]、[[メトロポリス・ヘイスティングス法]]、[[ギブスサンプリング]]：目標分布を定常分布にもつ連鎖の構成
- [[EMアルゴリズム]]：潜在変数と欠測データからの反復最尤推定

## 学び方と答案チェック

1. まず定義・条件を確認する（独立性、正規化、密度の台、モーメントの存在など）。
2. 独自例題の解答を隠した状態で解く。
3. 計算機を使わずに確率・期待値・分散を求め、必要なら電卓で検算する。
4. 「なぜその分布に従うのか」「なぜその近似が妥当か」を1〜3行で説明する。
5. 対応する過去問の原本で問題設定を確認する。
