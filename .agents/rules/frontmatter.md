# Frontmatter Rules

すべての学習用 `.md` ファイルの先頭にYAML frontmatterを置く。

基本形:

```yaml
---
test-category: 統計数理
stats-category: 確率
difficulty: 中
status: 正解
---
```

## test-category

試験上の分類。

原則として以下を用いる。

- `院試`
- `統計数理`
- `統計応用`

### 運用

- `01_現代数理統計学の基礎` は原則 `統計数理`
- `02_統計数理過去問` は `統計数理`
- `03_統計応用医薬生物学過去問` は `統計応用`
- `04_統計応用理工学過去問` は `統計応用`
- `05_院試過去問` は `院試`
- 統計検定1級範囲外で、院試対策を主目的とするノートには `院試` を使用できる

該当しない一般ノートでは、既存運用に合わせて空欄を許可する。

## stats-category

内容上の分類。

例:

- 集合
- 確率
- 確率分布
- 推定
- 検定
- 回帰
- 測度論
- ルベーグ積分
- 確率過程
- 確率微分方程式

`現代数理統計学の基礎` では同一章内の分類を原則統一する。
既存ノートの分類がある場合はそれを優先する。

## difficulty

以下の3値。

- `易`
- `中`
- `難`

AIが問題全体の難易度を判断して設定してよい。

## status

`status` は理解度ではなく、ユーザー答案の採点結果である。

確定値:

- `正解`
- `部分的なミスあり`
- `不正解`
- `回答なし`

判定基準は `.agents/references/grading-rubric.md` を参照する。

### 未採点時

公式解答が存在しない、読み取れない等の理由で採点できない場合、
推測で4値のいずれかを付けず、

```yaml
status:
```

のように一時的に空欄とする。

`回答なし` は「公式解答がない」という意味ではない。
ユーザー答案が存在しない・欠損している場合にのみ用いる。
