# Daily Notes rules

Obsidian Daily Noteはユーザーの学習日誌。

保存先:

```text
00_学習管理/Daily/YYYY-MM-DD.md
```

主な用途:

- 今日やる問題
- 実際に解いた問題
- 復習対象
- 今日理解した概念
- 疑問点
- 次回やること

ルートの `daily_report.md` はAI作業ログであり別物。
Daily Noteの内容を `daily_report.md` に丸ごとコピーしない。
