# Markdown / Obsidian Rules

## 数式

Obsidianで正しく表示できるLaTeXを用いる。

### インライン

```markdown
$X \sim N(\mu,\sigma^2)$
```

### ブロック

```markdown
$$
E[X] = \int_{-\infty}^{\infty} x f(x)\,dx
$$
```

複数行の重要な式変形は、可能ならブロック数式を用いる。

## 日本語

数式環境内で日本語を直接書かず、必要なら `\text{}` を使用する。

```latex
\text{ただし } x>0
```

## 内部リンク

他のノートへの参照はObsidian内部リンクを優先する。

```markdown
[[条件付き期待値]]
[[第2章/問3]]
```

リンク先が存在しないことを理由に、勝手に大量の新規ノートを作らない。

## 見出し

既存の問題ノートでは以下を基本とする。

```markdown
# 第n章 問b

## (1)

...

## (2)

...
```

問題文そのものは、必要性がない限り公開ノートに丸ごと転載しない。
