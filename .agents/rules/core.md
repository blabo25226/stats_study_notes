# Core Rules

## 1. 基本方針

このリポジトリは学習用ノートである。
文章の見栄えよりも数学的正確性を優先する。

AIの役割は以下である。

- 数式・証明・計算の補助
- 手書き数式のLaTeX化
- Markdown/Obsidian形式の整備
- R/Pythonによる検算やグラフ生成
- 公式解答を用いた答案の採点
- 関連ノート間のリンク整理
- 必要に応じたGitコミットメッセージ案の作成

## 2. Learning-first

ユーザーが問題を解いている途中では、完全解答を明示的に求められていない限り、
ヒント、誤りの位置、次の一手を優先する。

ただし、ユーザーが提出済み答案のMarkdown化・採点を依頼している場合は、
答案を忠実に転記し、その後に採点する。

## 3. User work preservation

手書き答案を転記するときは、以下を守る。

- ユーザーの式変形・論理展開を可能な限り保持する。
- 誤答を正答へ勝手に置換しない。
- 誤記を「転記時の都合」で修正しない。
- 判読不能箇所を推測で埋めない。
- 判読不能箇所は明示的に残すか、処理不能として扱う。

## 4. 採点

`status` は学習進捗ではなく採点結果である。

確定値は以下のみ。

- `正解`
- `部分的なミスあり`
- `不正解`
- `回答なし`

詳細は `.agents/references/grading-rubric.md` に従う。

## 5. 推測禁止

特に以下を推測で補完しない。

- 判読不能な手書き数式
- 問題番号
- 教科書ページ番号
- 公式解答の欠けた部分
- 数学的に重要な仮定
- 採点結果

確信できない場合は、元データを保持し、不確実性が分かる形にする。

## 6. 既存フォーマット仕様

`docs/format/` が存在する場合、その中の明示的なフォーマット指定を確認して従う。
`.agents/` の一般ルールと `docs/format/` の個別フォーマットが競合する場合は、
ユーザーの最新指示を最優先し、その次に対象ファイル用の具体的な指定を優先する。
