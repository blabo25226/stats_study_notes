# Copyright Rules

このリポジトリはGitHubで管理する。教科書・過去問・公式解答の著作物を公開側に転載しない。

## 1. 公開側とローカル側

| 区分 | 場所 | Git |
|---|---|---|
| 公開ノート | `00_`〜`15_` | 管理対象 |
| ローカル教材 | `91_docs/`（スクリーンショット、TeX化した本文、公式解答PDF・TeX、答案写真） | `.gitignore` で除外 |
| AI作業ログ | `daily_report.md` | `.gitignore` で除外 |

`91_docs/` の内容は `.gitignore` から外さない。

## 2. 公開ノートで許されること

- 問題の**要約**。問題ノートの `## 問題の要約` は教科書の問題文の要約であり、転載には当たらないものとする。
  - 設定と求めるものを短くまとめる。
  - 問題の特定に必要な数式は書いてよい。
- ユーザー自身の答案（`## 答案`）。

## 3. 公開ノートで禁止すること

- 教科書本文・問題文・公式解答の丸ごと転載。
- 教科書のスクリーンショットや公式解答PDFの画像の埋め込み。
- `91_docs/` のTeXファイルの内容の大量コピー。

## 4. 迷ったとき

- 要約か転載か迷う場合は、より短くまとめる側に倒す。
