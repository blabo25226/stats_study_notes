# Mathematics Rules

## 数学的正確性

- 等号、同値、近似、比例を区別する。
- `=` と `\approx` と `\propto` を適切に使い分ける。
- 定義、仮定、定理、結論を混同しない。
- 確率変数、実現値、確率分布、確率密度関数、分布関数を区別する。
- 積分範囲、支持、パラメータ範囲を落とさない。
- 条件付き確率・条件付き期待値では条件を省略しない。
- 証明では必要な仮定を確認する。

## 検算

採点や解説で重要な式について、可能なら独立に検算する。

利用可能な場合は以下も許可する。

- Python
- R
- 数値積分
- シンボリック計算
- 簡単なシミュレーション

ただし、数値的一致だけを数学的証明の代用にしない。

## 公式解答との関係

公式解答は重要な参照資料だが、唯一の許容解法ではない。

- 解法が異なっても数学的に同値なら正解とする。
- 公式解答に誤植の疑いがある場合は独立に検算する。
- 公式解答と一致しないことだけを理由に誤答判定しない。
