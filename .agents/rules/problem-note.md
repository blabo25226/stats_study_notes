# Problem Note Rules

問題ノート（1問題1ファイル）の本文構成。frontmatterは `frontmatter.md` に従う。

## 1. 対象範囲

『現代数理統計学の基礎』で問題を解くのは **第2章〜第7章のみ** とする。

```text
01_現代数理統計学の基礎/第2章/ 〜 第7章/
```

第1章および第8章以降の問題ノートは作らない。

## 2. 構成

問題ノートは次の3要素**のみ**で構成する。

1. frontmatter
2. `## 問題の要約`
3. `## 答案`

```markdown
---
test-category: 統計数理
stats-category: 標本分布
difficulty: 中
status: 部分的なミスあり
tags:
  - マルコフの不等式
  - 積率母関数
source: 現代数理統計学の基礎 第5章
created: 2026-09-26
updated: 2026-09-26
---

# 第5章 問6

## 問題の要約

（教科書の問題文の要約）

## 答案

### (1)

（答案）

### (2)

（答案）
```

- H1 `# 第n章 問b` はノートのタイトルとして置く。
- 見出しは `## 問題の要約` と `## 答案` の2つだけ。名前を変えない。

## 3. 問題の要約

- 教科書本文（`91_docs/.../第n章/latex/chaptern.tex` またはスクリーンショット）の問題文を要約する。
- 何を示す・求める問題かが分かるように、設定と求めるものを短く書く。
- 問題の特定に必要な数式（密度関数、統計量の定義など）は書いてよい。
- これは要約であり、教科書の転載には当たらないものとする（`copyright.md`）。
- 小問は `(1) ...、(2) ...` のように1段落にまとめるか、改行して並べる。

## 4. 答案

- ユーザーが紙で解いた答案を、Gemini等のAIがTeX（Obsidian互換Markdown数式）に書き起こしたもの。
- 答案の論理展開・途中式・記法をそのまま保つ。誤りがあっても直さない。
- 小問は `### (1)` のように `###` で分ける。
- 回答なしの場合は本文を `答案未提出` の1行とする。
- 解き直した場合は、`## 答案` の中に `### 解き直し（YYYY-MM-DD）` を追加する。

## 5. 書かないもの

以下は問題ノートに書かない。

- 目次
- 採点・判定理由・講評
- 解説・模範解答・公式解答
- 関連知識・発展事項
- 内部リンクの `## 関連` 節（内部リンクは保留中）

採点結果はfrontmatterの `status` だけに残す。
判定理由はユーザーへの報告と `daily_report.md` に書く（`grading-rubric.md` §4）。
