# Daily Report Rules

## Purpose

ルートの `daily_report.md` は、AIがその日に行った学習支援・ファイル処理・採点作業を記録する作業ログである。

これはObsidianの

```text
00_学習管理/Daily/YYYY-MM-DD.md
```

とは別物である。

- `daily_report.md`: AI作業ログ
- `00_学習管理/Daily/`: ユーザーの学習日誌・復習計画

## When to update

以下のどちらかを満たす場合に更新する。

1. まとまった作業が終了したとき
2. ユーザーから更新を指示されたとき

単純な質問への回答だけで、リポジトリ内の学習作業を行っていない場合は、
不要な日報追記をしなくてよい。

## What to record

最低限、以下を記録する。

- 日付
- その日の学習内容
- 作成したファイル
- 更新したファイル
- 採点した問題と `status`
- 躓いたポイント・誤りの傾向
- 未完了事項または次に確認すべき事項

## Append only

既存の日報内容を消さない。
当日のセクションが既に存在する場合は、そのセクションへ追記・統合する。
重複する同一内容は増やさない。

## Grading

採点を行った場合は、必要に応じて次を残す。

```text
問3: 正解
問4: 部分的なミスあり — 符号ミス
問5: 不正解 — 尤度の立式から再確認
```

詳細解答そのものを `daily_report.md` に複製しない。

## Git

`daily_report.md` は `.gitignore` 対象であり、原則としてGit管理しない。
AIは日報更新後も勝手にcommit / pushしない。
