# Build Dashboard

対象:

```text
00_学習管理/Home.md

```

## Principles

- ノートデータをダッシュボードへ複製しない。
- PropertiesをBaseから参照する。
- Baseは目的ごとに分ける。
- HomeはBaseとMOCへの入口として短く保つ。
- `.base` は有効なYAMLを保つ。
