# Skill: Official Answer to TeX

## Purpose

『現代数理統計学の基礎』の公式解答資料を読み取り、
章・問題番号に対応したTeXへ整理する。

生成されたTeXは、手書き答案の採点時に参照する。

## Trigger

以下に公式解答の画像・PDF・スクリーンショット等が入ったときに使用する。

```text
91_docs/materials/現代数理統計学の基礎/第n章/答え/
```

資料が複数章を含む場合は、内容を確認して適切な章へ振り分ける。

## Output

章ごとに1つ:

```text
91_docs/materials/現代数理統計学の基礎/第n章/latex/answers.tex
```

---

## Procedure

### Step 1: 資料の範囲を特定する

入力資料から以下を確認する。

- 章番号
- 問題番号
- 小問番号
- 何問から何問まで含まれるか

ファイル名だけで判断せず、可能なら内容を確認する。

### Step 2: 適切な章へ振り分ける

例:

```text
第2章 問1〜16
```

なら

```text
91_docs/materials/現代数理統計学の基礎/第2章/latex/answers.tex
```

へ入れる。

1つの入力資料が複数章を含む場合は、
章ごとに分けてそれぞれの `answers.tex` に整理する。

### Step 3: 問題単位で構造化する

`answers.tex` 内では各問題を明確に識別できるようにする。

例:

```tex
% 第2章 公式解答

\subsection*{問1}

...

\subsection*{問2}

...

\subsection*{問3}

...
```

小問は必要に応じて以下のようにする。

```tex
\paragraph{(1)}
...

\paragraph{(2)}
...
```

### Step 4: 既存 answers.tex と統合する

既に `answers.tex` が存在する場合:

- 既存内容を無条件に上書きしない。
- 今回追加された問題範囲を特定する。
- 同じ問題の重複を作らない。
- より完全なソースが来た場合は、該当部分のみ更新する。
- 別の問題の解答を消さない。

### Step 5: 忠実にTeX化する

公式解答の内容を、採点参照に十分な精度でTeX化する。

特に以下を正確にする。

- 数式
- 条件
- 場合分け
- 結論
- 問題番号
- 小問番号

判読不能な箇所を推測で補完しない。

### Step 6: 数学的検算

公式解答に明らかな誤植・計算ミスの疑いがある場合は、
勝手に原文を改変せず、TeX中にコメント等で疑義を残す。

例:

```tex
% NOTE: 原資料の式は誤植の可能性あり。採点時に独立検算すること。
```

原文転記とAIによる補正を混同しない。

### Step 7: 採点Skillとの連携

`answer-photo-to-markdown` は、原則としてこのファイルを参照する。

```text
第n章/latex/answers.tex
```

そのため、問題番号が検索可能な構造を維持する。

### Step 8: 完了確認

- 適切な章に保存されている
- 問題番号の範囲が正しい
- `answers.tex` が章ごとに1つ
- 既存問題を誤って削除していない
- 数式を正確に転記した
- 判読不能箇所を捏造していない
- Git commit / pushをしていない
