# Skill: Official Answer PDF to Chapter TeX

## Purpose

『現代数理統計学の基礎』全体の公式解答PDFを読み取り、
章ごとに対応範囲を特定し、各章の `答え/answers.tex` に分割してTeX化する。

生成された章別TeXは、手書き答案の採点時に参照する。

---

## Source

公式解答の原本は以下の1ファイルである。

Windows上の実体:

```text
C:\Document\数理統計学勉強\91_docs\materials\現代数理統計学の基礎\解答\MathStat_Answers.pdf
```

リポジトリルートから見た相対パス:

```text
91_docs/materials/現代数理統計学の基礎/解答/MathStat_Answers.pdf
```

このPDFは『現代数理統計学の基礎』全体の公式解答を含む。

---

## Output

章ごとに以下へ保存する。

```text
91_docs/materials/現代数理統計学の基礎/第n章/答え/answers.tex
```

例:

```text
91_docs/materials/現代数理統計学の基礎/第2章/答え/answers.tex
91_docs/materials/現代数理統計学の基礎/第3章/答え/answers.tex
91_docs/materials/現代数理統計学の基礎/第4章/答え/answers.tex
```

`latex/` ではなく、必ず各章の `答え/` に置く。

---

## Procedure

### Step 1: PDF全体の構造を確認する

まず

```text
91_docs/materials/現代数理統計学の基礎/解答/MathStat_Answers.pdf
```

を開き、以下を確認する。

- PDF全体のページ数
- 第何章の解答がどのPDFページ範囲にあるか
- 各章で何問まで解答が含まれるか
- 章見出しや問題番号の表記

ファイル名だけから章範囲を推測しない。

### Step 2: 章ごとのページ範囲を特定する

PDF内の章見出しと問題番号を読み、
各章について開始ページ・終了ページを特定する。

例:

```text
第2章: PDF p.5 - p.11
第3章: PDF p.12 - p.18
...
```

この対応はPDFの実内容から判断する。

教科書本体のページ番号とPDFビューア上のページ番号を混同しない。

### Step 3: 章単位でTeX化する

各章の該当範囲だけを読み取り、

```text
91_docs/materials/現代数理統計学の基礎/第n章/答え/answers.tex
```

を作成する。

1章につき1つの `answers.tex` とする。

### Step 4: 問題単位で構造化する

`answers.tex` 内では、各問題を明確に識別できるようにする。

例:

```tex
% 現代数理統計学の基礎 第2章 公式解答
% Source: MathStat_Answers.pdf

\subsection*{問1}

...

\subsection*{問2}

...

\subsection*{問3}

...
```

小問がある場合:

```tex
\paragraph{(1)}
...

\paragraph{(2)}
...
```

### Step 5: 原資料を忠実にTeX化する

採点参照に十分な精度で、以下を正確に転記する。

- 数式
- 条件
- 場合分け
- 問題番号
- 小問番号
- 最終結果
- 解答上重要な説明

数式では特に以下を落とさない。

- 添字・上付き
- 積分範囲
- 総和範囲
- 絶対値
- 条件
- 定数
- 分布パラメータ

判読不能箇所を推測で補完しない。

### Step 6: 既存ファイルがある場合

既に

```text
第n章/答え/answers.tex
```

が存在する場合は、無条件に全体を上書きしない。

以下を確認する。

- 今回のPDF由来の内容と既存内容の対応
- 欠落している問題
- 重複している問題
- 既存の手修正や注記

PDF原本を基準に不足分を補い、
別問題の解答を消さない。

### Step 7: 公式解答に疑義がある場合

原資料に明らかな誤植・計算ミスの可能性がある場合、
原文を勝手に正しい形へ改変しない。

必要ならTeXコメントとして残す。

```tex
% NOTE: 原資料の式は誤植の可能性あり。採点時に独立検算すること。
```

原資料の転記とAI独自の訂正を混同しない。

### Step 8: 章間の混入を確認する

保存前に必ず確認する。

- 第2章の解答が第3章の `answers.tex` に入っていないか
- 問題番号の切り替わり位置は正しいか
- 章末の最後の問題が欠落していないか
- 次章の最初の問題を誤って含めていないか

### Step 9: 完了条件

各章について以下を満たすこと。

- 元PDFの該当章範囲を確認済み
- `第n章/答え/answers.tex` が存在する
- 問題番号が検索可能
- 数式がTeXとして妥当
- 他章の内容が混入していない
- 判読不能箇所を捏造していない
- Git commit / pushをしていない

---

## Important

このSkillでは、

```text
第n章/答え/
```

に「元のPDFを分割して置く」のではなく、
全章共通の

```text
解答/MathStat_Answers.pdf
```

を参照し、各章に対応する範囲だけをTeXへ変換する。

公式解答の原本PDFは移動・削除しない。
