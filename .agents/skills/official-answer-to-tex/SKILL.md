# Skill: Official Answer PDF to Chapter TeX

## Purpose

『現代数理統計学の基礎』全体の公式解答PDFを章ごとに読み分け、各章の `答え/answers.tex` にTeX化する。
採点時に参照するためのローカル資料であり、公開ノートには転載しない。

## Trigger

公式解答PDFから章別の解答TeXを作成・更新するよう指示されたとき。

## Input

```text
91_docs/materials/現代数理統計学の基礎/解答/MathStat_Answers.pdf
```

## Output

```text
91_docs/materials/現代数理統計学の基礎/第n章/答え/answers.tex
```

以下は誤り。

```text
第n章/latex/answers.tex          (latex/ は教科書本文用)
解答/chaptern.tex                 (原本フォルダには置かない)
```

## Procedure

### Step 1: 章の範囲を特定する

- PDFのページ柱（ヘッダー）は全ページで同じ文言が印字されていることがあるため、柱だけで判断しない。
- 本文中の章見出し（例: `2.5 第5章`）と問題番号の並び（問1から始まる）で章の開始・終了ページを決める。
- 決めたページ範囲をファイル冒頭のコメントに記録する。

### Step 2: テキストを抽出する

- PDFのテキスト抽出を基本とし、数式が崩れている箇所はページ画像を見て確認する。
- 判読できない箇所は `% 【判読不能】` とコメントし、推測で補わない。

### Step 3: TeXを書く

形式:

```tex
% 現代数理統計学の基礎 第5章 公式解答
% Source: MathStat_Answers.pdf (pp. 85-102)

% --- Page 85 ---
問1. ...

% --- Page 86 ---
...
```

- ページ境界に `% --- Page N ---` を入れる。
- 問題番号 `問b.` を行頭に置き、検索しやすくする。
- 可能な範囲で数式を `$...$` / `\[...\]` に整える。抽出テキストのままの箇所が残ってもよいが、
  採点で使う問題の数式は画像で確認してから使う。

### Step 4: 既存 answers.tex がある場合

- 無条件に上書きしない。
- 数式を手で整えた箇所を失わないよう、差分で更新する。

### Step 5: 完了確認

- [ ] 出力先が `第n章/答え/answers.tex`
- [ ] ページ範囲が冒頭コメントに記録されている
- [ ] 章の最初と最後の問題が漏れていない
- [ ] 別の章の解答が混ざっていない
- [ ] 判読不能箇所を捏造していない
- [ ] 公開ノート（`01_`〜）に内容を転載していない
