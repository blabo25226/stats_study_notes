# Skill: Update Daily Report

## Purpose

AIの作業内容をリポジトリ直下の `daily_report.md` に記録する。

`daily_report.md` はAI作業ログであり、Obsidian Daily Note（`00_学習管理/Daily/YYYY-MM-DD.md`）とは別物。
Daily Noteの内容をここにコピーしない。Daily Noteの作成・更新はClaudeのみの担当（`AGENTS.md` の「AI roles」）。

Claude・Geminiのどちらも、このスキルに従って `daily_report.md` に追記する。

`daily_report.md` は `.gitignore` で除外されている。

## Trigger

- 作業終了時
- ユーザーから日報更新を指示されたとき

## Rules

- 既存内容を消さない。末尾に追記する。
- 同じ日の見出しがすでにあれば、その日の項目に追記する（見出しを重複させない）。
- 事実だけを書く。行っていない作業、確認していない結果を書かない。
- どのAIが作業したかを「作業AI」に書く。
- 問題ノートには採点理由を書かないため（`problem-note.md` §5）、採点した問題の判定理由はここに残す。

## Format

年 `#`、月 `##`、日 `###` の3階層。

```markdown
# 2026
## 09
### 26
- **作業AI**: Claude / Gemini
- **学習・作業内容**:
  - （何をしたか）
- **作成・更新ファイル**:
  - `01_現代数理統計学の基礎/第6章/問1.md` ～ `問18.md`（新規作成）
- **採点結果**:
  - **第6章**: 全18問中、正解 8問（問1, 3, ...）、部分的なミスあり 7問（...）、回答なし 3問（...）
  - **判定理由**:
    - 第6章 問2: 部分的なミスあり — (i) 正しい。(ii) 分散の計算で係数を誤っている。
    - 第6章 問4: 部分的なミスあり — ...
- **躓いたポイント / 注意点**:
  - （問題が起きたこと、その解決方法）
- **次回**:
  - （次にやること）
```

- 該当しない項目（採点がなかった日の「採点結果」など）は省略する。
- ファイルパスはリポジトリルートからの相対パスで書き、バッククォートで囲む。
- 連番のファイルは `問1.md` ～ `問18.md` のようにまとめる。
- 年・月が変わったら `# YYYY` / `## MM` の見出しを追加する。

## 完了確認

- [ ] 既存内容が残っている
- [ ] 日付の見出しが重複していない
- [ ] 採点結果の件数が各ノートの `status` と一致している
- [ ] Daily Noteと混同していない
