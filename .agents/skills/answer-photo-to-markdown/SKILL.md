# Skill: Answer Photo to Markdown

## Purpose

`現代数理統計学の基礎` の章末問題について、
ユーザーの手書き答案写真を整理し、Obsidian用Markdownへ忠実に転記し、
公式解答を参照して採点する。

## Trigger

以下に新しい答案画像が入ったときに使用する。

```text
91_docs/materials/現代数理統計学の基礎/第n章/回答/
```

## Inputs

- 答案画像
- 必要に応じて同章の教科書TeX
- 同章の公式解答TeX

公式解答の標準参照先:

```text
91_docs/materials/現代数理統計学の基礎/第n章/latex/answers.tex
```

## Output

```text
01_現代数理統計学の基礎/第n章/問b.md
```

1問題につき1Markdownファイルとする。

---

## Procedure

### Step 1: 入力ファイルを確認する

`回答/` 内の新規画像を一覧化する。

画像内容から以下を確認する。

- 章番号 `n`
- 問題番号 `b`
- 同一問題に何枚の写真があるか
- 各写真の順序

問題番号を画像内容から確実に判定できない場合は、推測で別問題へ割り当てない。

### Step 2: ファイル名を正規化する

問題 `b` の `c` 枚目を次の形式にする。

```text
問b_c.jpg
```

例:

```text
問3_1.jpg
問3_2.jpg
問3_3.jpg
```

`c` は1から始める。

注意:

- 元画像がJPEGなら拡張子を `.jpg` に統一してよい。
- PNG等を単に拡張子だけ `.jpg` に変更してはならない。
- `.jpg` へ統一する場合は実際の画像形式もJPEGへ変換する。
- 変換手段がない場合はデータ破損を避け、実体に合う拡張子を保持する。

### Step 3: 答案を読み取る

手書き答案をページ順に読み取る。

最重要ルール:

- ユーザーの式変形を保持する。
- 誤答を勝手に直さない。
- 別解に置換しない。
- 書かれていない説明を捏造しない。
- 判読不能箇所を推測で埋めない。

### Step 4: Markdownへ転記する

出力先:

```text
01_現代数理統計学の基礎/第n章/問b.md
```

既存ファイルがある場合は、既存内容と今回の答案を比較し、
ユーザー答案を不必要に失わないように更新する。

形式:

```yaml
---
test-category: 統計数理
stats-category: <章に対応する分類>
difficulty: <易|中|難>
status:
---
```

本文:

```markdown
# 第n章 問b

## (1)

...

## (2)

...
```

教科書の問題文全文は公開Markdownへ転記しない。
答案を理解するのに必要な最小限の前提・式のみ使用する。

### Step 5: 公式解答を確認する

以下を優先して参照する。

```text
91_docs/materials/現代数理統計学の基礎/第n章/latex/answers.tex
```

必要な `問b` の部分を特定する。

公式解答TeXがない場合は、
`答え/` に元資料が存在するかを確認する。

公式解答を確認できない場合は採点を推測せず、

```yaml
status:
```

のままとする。

### Step 6: 独立に数学を確認する

公式解答と答案を機械的に文字列比較してはならない。

確認事項:

- 最終結果
- 途中計算
- 仮定
- 条件
- 論理の妥当性
- 別解として成立しているか

公式解答と異なる方法でも数学的に正しければ正解とする。

### Step 7: status を決定する

`.agents/references/grading-rubric.md` に従い、次のいずれかを設定する。

```text
正解
部分的なミスあり
不正解
回答なし
```

#### 回答なし

以下の場合は `回答なし`。

- 対応する答案写真がない
- 答案画像が欠損している
- 必須ページが失われている
- 破損等で回答を確認できない
- 実質的に未回答

公式解答がないことを理由に `回答なし` としてはならない。

### Step 8: 保存前チェック

- frontmatterがある
- `status` が採点結果になっている
- 数式がObsidianで表示できる
- ユーザー答案を勝手に修正していない
- 問題文全文を公開側に転載していない
- ファイル名が `問b.md`
- Git commit / pushをしていない

---

## Existing files

過去に

```yaml
status: 一度解けた
```

等が使われている既存ノートを更新する場合、
答案と公式解答を実際に確認したうえで新しい採点statusへ置き換える。

一括で推測変換してはならない。
