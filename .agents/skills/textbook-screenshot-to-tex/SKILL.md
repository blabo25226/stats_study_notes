# Skill: Textbook Screenshot to TeX

## Purpose

『現代数理統計学の基礎』の教科書スクリーンショットを整理し、
AIが参照可能なTeXへ変換する。

このTeXはローカル教材領域 `91_docs/` 内で使用する。

## Trigger

以下に新しいスクリーンショットが入ったときに使用する。

```text
91_docs/materials/現代数理統計学の基礎/第n章/スクリーンショット/
```

## Output

画像:

```text
91_docs/materials/現代数理統計学の基礎/第n章/スクリーンショット/pAA.png
```

TeX:

```text
91_docs/materials/現代数理統計学の基礎/第n章/latex/pAA.tex
```

`AA` は教科書の実ページ番号。

---

## Procedure

### Step 1: 新規画像を確認する

スクリーンショットの内容とページ番号を確認する。

ページ番号が画像内で明確に確認できる場合は、その番号を使用する。

例:

```text
p37.png
p38.png
p39.png
```

ページ番号を確実に確認できない場合、推測で番号を割り当てない。

### Step 2: 画像名を正規化する

画像がPNGなら:

```text
pAA.png
```

JPEGなら、実体と拡張子を一致させる。

拡張子だけを変更して画像形式を偽装しない。

### Step 3: TeX化する

各ページにつき1つのTeXファイルを作る。

```text
latex/pAA.tex
```

基本方針:

- 数式は正確にLaTeX化する。
- 添字、上付き、積分範囲、総和範囲を落とさない。
- 定理番号、式番号、見出し等は識別可能な範囲で保持する。
- 判読不能箇所を推測で補完しない。
- OCR誤りが数学的意味を変えないよう確認する。

### Step 4: TeXファイル形式

TeXは参照用の本文断片として保存する。
各ファイルを独立コンパイル可能な完全文書にする必要はない。

例:

```tex
% Source: 第2章 p.37

\section*{第2章}

本文...

\[
P(A \cap B) = P(A)P(B)
\]
```

### Step 5: 対応関係を守る

必ず

```text
p37.png  <->  latex/p37.tex
```

のように1対1対応させる。

同一ページのTeXを複数名で重複生成しない。

### Step 6: 公開ノートへコピーしない

教科書ページの全文TeXを

```text
01_現代数理統計学の基礎/
```

へそのままコピーしない。

公開側にはユーザーの学習ノート・答案を置く。

### Step 7: 完了確認

- ページ番号が正しい
- 画像形式と拡張子が一致
- 1ページ1TeX
- 数式がLaTeXとして妥当
- 判読不能箇所を捏造していない
- Git commit / pushをしていない
