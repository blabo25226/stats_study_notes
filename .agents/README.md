# .agents

教材処理・採点・模試作成・レビュー・Obsidian Vault管理の共通ルールとスキル。入口は `AGENTS.md`。

Codex・Claude・Geminiなど、利用するAIにかかわらず同じルールを使う。
現在の作業環境と読み込み方は `references/environment.md` を参照する。

## 基準となるファイル

| 対象 | 唯一の基準 |
|---|---|
| パス・命名・入出力先 | `references/canonical-paths.md` |
| frontmatter | `rules/frontmatter.md` |
| 分類の語彙 | `references/taxonomy.md` |
| 採点 | `references/grading-rubric.md` |

各SkillやRuleにパスやfrontmatterが書かれている場合も、上のファイルと一致させる。
矛盾がある場合はユーザーの最新指示を最優先し、次に上のファイルを優先する。

## 構成

全ファイルの役割と参照する場面は [指示ファイルの解説](references/repository-map.md#4-指示ファイルの解説) を参照する。
