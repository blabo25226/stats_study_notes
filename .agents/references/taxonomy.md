# Taxonomy

frontmatterの分類Properties（`test-category`, `stats-category`, `difficulty`, `tags`）で使う語彙。
キーの順序・表記は `.agents/rules/frontmatter.md` に従う。

## 1. test-category

| 値 | 意味 |
|---|---|
| `統計数理` | 統計検定1級 統計数理の範囲 |
| `統計応用` | 統計検定1級 統計応用の範囲 |
| `準1級` | 統計検定準1級の範囲 |
| `院試` | 大学院入試 |
| `数学` | 一般数学・測度論・確率論など、統計検定の範囲外 |

『現代数理統計学の基礎』の章末問題は `統計数理` とする。

### 過去問・その他

## 3. difficulty

| 値 | 目安 |
|---|---|
| `易` | 定義・公式の直接適用で解ける。数行〜十数行の計算 |
| `中` | 標準的な導出。複数の定理・手法の組み合わせが必要 |
| `難` | 非自明な証明、極限・漸近論の精密な評価、長い計算、発想が必要 |

難易度はAIまたはユーザーが問題内容から判断する。ユーザーが指定した場合はそれを優先する。

## 4. tags

- 数学的トピックを2〜8個程度付ける。
- 汎用タグ（`数理統計学`, `現代数理統計学の基礎`, `統計学`, `演習問題`, `統計検定1級`）は付けない。
- 新しいタグを作る前に既存タグを検索する。
