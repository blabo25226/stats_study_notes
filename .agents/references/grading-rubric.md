# Grading Rubric

問題ノートの `status` を決めるための採点基準。

## 1. status の4値

| status | 基準 |
|---|---|
| `正解` | 全小問について、結論が正しく、導出に数学的な誤り・飛躍がない |
| `部分的なミスあり` | 一部の小問のみ正解、または結論は正しいが導出に誤り・重要な飛躍がある、または途中で止まっている |
| `不正解` | 解答はあるが、主要な結論が誤っている、または方針が根本的に誤っている |
| `回答なし` | 答案が提出されていない、または白紙・問題の書き写しのみ |

`status` は採点結果専用であり、理解度・復習状態を表さない。
復習状態は `review-count`, `last-reviewed`, `next-review` で管理する。

## 2. 判定の詳細

### 正解とするもの

- 公式解答と異なる解法でも、数学的に正しく完結していれば `正解`。
- 答えの形が異なっても同値であれば `正解`（例: $\frac{1}{2-s}$ と $(2-s)^{-1}$）。
- 自明な変形の省略、表記の揺れ（$V(X)$ と $\mathrm{Var}(X)$ など）は減点しない。
- 途中で軽微な書き損じがあっても、直後で正しく処理され結論に影響しない場合は `正解`。
  ただし判定理由として報告する（§4）。

### 部分的なミスありとするもの

- 小問の一部が誤り・未解答。
- 結論は正しいが、以下のような不備がある。
  - 台（サポート）・パラメータ範囲・存在条件の欠落が結論に影響する
  - 不等号の向き、符号、係数の誤りを途中で打ち消している
  - 証明問題で重要な一歩（収束の根拠、交換の正当化など）が抜けている
- 方針は正しいが計算の途中で止まっている。

### 不正解とするもの

- 主要な結論（求める分布、推定量、値）が誤っている。
- 示すべき命題と異なる命題を示している。
- 循環論法、または結論を仮定している。

### 回答なしとするもの

- 答案写真がない、または白紙。
- 「答案未提出」と明記されている。

## 3. 複数の小問がある場合

- 全小問が正解 → `正解`
- 全小問が未解答 → `回答なし`
- 全小問が不正解 → `不正解`
- それ以外（正解と誤り・未解答が混在） → `部分的なミスあり`

## 4. 採点結果の記録

問題ノートには採点・解説を書かない（`.agents/rules/problem-note.md` §5）。

| 何を | どこに |
|---|---|
| 判定（4値） | ノートのfrontmatter `status` |
| 判定理由（小問ごと） | ユーザーへの報告、`daily_report.md` の「採点結果」 |
| 誤りの指摘・正しい導出 | ユーザーへの報告（求められた場合） |

判定理由は小問ごとに短く書く。

```markdown
- 第5章 問6: 部分的なミスあり — (1) 証明が途中で止まっている。(2) 正しい。
```

## 5. 公式解答がない場合

- 公式解答（`91_docs/materials/.../第n章/答え/answers.tex`）を確認できない場合、推測で採点しない。
- AIが独自に検証して明らかに正しい・誤りと言える場合も `status` は確定させない。
  `status:` を空にしておき、「公式解答未確認」とユーザーに報告して確認を求める。
- 公式解答自体に誤りがあると判断した場合は、根拠をユーザーに報告し、採点は数学的に正しい側で行う。

## 6. 再採点

- 解き直しの答案で採点が変わった場合は `status` を更新し、`updated` を当日にする。
- 過去の判定は `daily_report.md` に残っているので、ノートには履歴を書かない。
