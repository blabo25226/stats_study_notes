# Grading Rubric

`status` は公式解答を参照した採点結果を表す。

## 正解

以下を満たす場合。

- 最終結果が正しい。
- 論理・計算が本質的に正しい。
- 必要な条件を大きく落としていない。
- 公式解答と異なる方法でも数学的に正しい。

軽微な表記揺れや、結果・論理に影響しない小さな省略は許容する。

## 部分的なミスあり

解法の主要部分は正しいが、局所的な修正が必要な場合。

例:

- 符号ミス
- 軽微な計算ミス
- 定数倍のミス
- 条件の一部欠落
- 複数小問のうち一部のみ誤り
- 主要方針は正しいが途中の論証が不十分
- 正答へ比較的小さな修正で到達できる

## 不正解

解法の中心部分または結論に本質的な誤りがある場合。

例:

- 使用する分布や定理が誤っている
- 問題の条件を本質的に取り違えている
- 結論が誤っており、大幅な解き直しが必要
- 偶然最終式だけ合っていても、根拠となる論理が成立していない

## 回答なし

ユーザー答案を採点できる実体が存在しない場合。

例:

- 対応する答案写真がない
- 写真ファイルが欠損している
- 必要なページが欠落し、答案全体を確認できない
- ファイル破損等により回答を読み取れない
- 問題に対して実質的な回答がない

## 公式解答がない場合

公式解答の不在・未処理は `回答なし` ではない。

その場合は採点を保留し、

```yaml
status:
```

とする。

## 採点原則

1. ユーザー答案を忠実に読む。
2. 公式解答を読む。
3. 公式解答の解法を唯一の解法だとみなさない。
4. 数学的同値性を確認する。
5. 必要なら独立に検算する。
6. その後 `status` を決定する。
