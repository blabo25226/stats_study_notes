\chapter{同等性・非劣性・生物学的同等性}\label{ch:13}

\begin{goalbox}
\begin{itemize}
\item 優越性・同等性・非劣性の帰無仮説と対立仮説を書き分けられる．
\item 「有意差なし」と「同等」が異なることを，信頼区間を用いて説明できる．
\item 生物学的同等性の判定規則（対数変換した差の90\%信頼区間が $(\log0.80,\log1.25)$ に含まれる）を述べ，適用できる．
\item 2剤2期クロスオーバー試験のデータを被験者ごとの対数値の差として扱い，幾何平均比の90\%信頼区間を計算できる．
\end{itemize}
\end{goalbox}

\begin{exambox}
\begin{itemize}
\item \kakomon{2016}{4}〔5〕：10名のクロスオーバー試験で，被験者ごとの対数 AUC の差（$\bar Y=0.1$，$s=0.5$）から中央値の比の90\%CI $(0.83,1.48)$ を求め，同等域 $(0.8,1.25)$ に含まれないので生物学的同等でないと判定（\cref{sec:13-be}）．
      同問〔1〕〜〔4〕の対数正規分布の性質（密度・平均・分散・変動係数）は，積率母関数が与えられた誘導問題である（\cref{app:F}）．
\item \kakomon{2021}{2}：〔1-2〕〔1-3〕の2つの片側検定とその組合せの第1種の過誤確率は，仮説と手順が問題文で与えられた誘導問題（\cref{app:F}）．
      〔2〕は20名の対数差（平均 $-0.1$，SD $0.26$）と $\Delta=\log1.25$ による判定で，90\%CI $[-0.201,0.001]\subset(-0.223,0.223)$ から同等．
\end{itemize}
\end{exambox}

\section{問題設定：3種類の比較}\label{sec:13-setting}
試験治療 $T$ と対照 $C$ の差（または対数比）を $\theta=\mu_T-\mu_C$（大きいほど $T$ が良い）とし，臨床的に許容できる差（マージン）を $\Delta>0$ とする．
\begin{table}[htbp]
\centering\small
\caption{3種類の比較の仮説}\label{tab:13-hyp}
\begin{tabular}{@{}lll@{}}
\toprule
目的 & 帰無仮説 $H_0$ & 対立仮説 $H_1$\\
\midrule
優越性（superiority） & $\theta\le0$ & $\theta>0$\\
非劣性（non-inferiority） & $\theta\le-\Delta$ & $\theta>-\Delta$\\
同等性（equivalence） & $\theta\le-\Delta$ または $\theta\ge\Delta$ & $-\Delta<\theta<\Delta$\\
\bottomrule
\end{tabular}
\end{table}
同等性・非劣性では「示したいこと（同等・劣らない）」を対立仮説に置く．
\begin{warnbox}[「有意差なし」と「同等」]
優越性の検定で $H_0:\theta=0$ が棄却されないことは，差がないことの証拠ではない．症例数が少なければ大きな差があっても有意にならない．
同等性は，信頼区間全体が $(-\Delta,\Delta)$ に含まれること（差が大きい可能性をデータが否定すること）で示す．
\cref{reidai:13-2}は，$t$ 検定で有意差がないのに同等性も示せない例である．
\end{warnbox}

\section{同等性の判定：信頼区間による規則}\label{sec:13-equiv}
\Hissu
差の標本 $Y_1,\dots,Y_n\iid\Normal(\theta,\sigma^2)$（$\sigma^2$ 未知），標本平均 $\bar Y$，不偏分散 $s^2$ とする．
\begin{pointbox}[同等性の判定規則]
$\theta$ の $100(1-2\alpha)\%$ 信頼区間 $\bar Y\pm t_{n-1}(\alpha)\,s/\sqrt n$ が $(-\Delta,\Delta)$ に含まれれば同等と判定する．
$\alpha=0.05$ なら\textbf{90\%信頼区間}を用いる．
\end{pointbox}
90\%区間を使うのは，この規則が「$H_{01}:\theta\le-\Delta$ と $H_{02}:\theta\ge\Delta$ をそれぞれ片側5\%の $t$ 検定で検定し，両方とも棄却されたら同等とする」手順と同値だからである
（下限 $>-\Delta$ が前者の棄却，上限 $<\Delta$ が後者の棄却にあたる）．各片側検定を2.5\%にする必要はない．

\section{非劣性試験}\label{sec:13-ni}
\begin{itemize}
\item 標準治療より副作用が少ない・投与が簡便などの利点がある新治療で，「有効性が許容範囲を超えて劣らない」ことを示す．
\item 判定（片側2.5\%）：$\theta$ の95\%CI の下限 $>-\Delta$．下限が0も上回れば，続けて優越性も主張できる（非劣性→優越性の順に検定する固定順序の手順．\cref{sec:14-closed}）．
\item マージン $\Delta$ はデータを見る前に，臨床的判断と過去のプラセボ対照試験の効果の大きさから決める．
\end{itemize}

\section{生物学的同等性}\label{sec:13-be}
\Hissu\Hinshutsu
\subsection{対数変換と幾何平均比}
薬物動態パラメータ（AUC，$C_{\max}$）は正の値をとり右に歪むので，対数をとった $Y=\log X$ が正規分布 $\Normal(\mu,\sigma^2)$ に従う（$X$ は対数正規分布に従う）とモデル化する．
$\log$ は単調増加なので $\Prob(X\le e^\mu)=\Prob(Y\le\mu)=1/2$，すなわち $X$ の中央値は $e^\mu$ である．
したがって対数スケールの平均の差 $\mu_T-\mu_R$ を指数変換した $e^{\mu_T-\mu_R}$ は，中央値の比（幾何平均の比，GMR）である（\kakomon{2021}{2}〔2-1〕）．

\subsection{判定規則}
\begin{pointbox}[生物学的同等性の判定（\kakomon{2016}{4}〔5〕）]
AUC と $C_{\max}$ の対数値の平均の差 $\mu_T-\mu_R$ の90\%信頼区間が $(\log0.80,\log1.25)$ に含まれる
（同じことだが，指数変換した GMR の90\%信頼区間が $(0.80,1.25)$ に含まれる）とき生物学的に同等と判定する
（後発医薬品の生物学的同等性試験ガイドライン \cite{jp:be}）．
\end{pointbox}
これは\cref{sec:13-equiv}の規則で $\Delta=\log1.25$ としたものである．$\log1.25=0.2231=-\log0.80$ なので，同等域は対数スケールで $0$ に関して対称である．
同等でない製剤が合格する確率（消費者危険）は5\%以下に抑えられる．
\paragraph{判定の手順}
\begin{enumerate}
\item AUC を対数変換し，被験者ごとの差 $d_i=\log X_i^T-\log X_i^R$ を求める．
\item 対応のある差の $t$ 区間 $\bar d\pm t_{n-1}(0.05)\,s_d/\sqrt n$ を計算する．
\item 指数変換して GMR の90\%CI を得て，$(0.80,1.25)$ に含まれるかを判定する（対数スケールのまま $(-0.2231,0.2231)$ と比べてもよい）．
\end{enumerate}
\kakomon{2016}{4}〔5〕：$\bar Y=0.1$，$s=0.5$，$n=10$，$t_9(0.05)=1.833$ から $0.1\pm0.29=(-0.19,0.39)$，
GMR（既存薬/後発品）の区間 $(0.83,1.48)$ は上限が1.25を超え，同等とは言えない．\\
\kakomon{2021}{2}〔2-2〕：$\bar d=-0.1$，$s=0.26$，$n=20$，$t_{19}(0.05)=1.729$ から $[-0.201,0.001]\subset(-0.223,0.223)$ で同等．

\subsection{2剤2期クロスオーバー試験を対応ありの差で扱う}\label{subsec:13-crossover}
系列 TR（第1期T，第2期R）に $n_1$ 人，RT に $n_2$ 人を割り付け，被験者 $i$ の第 $p$ 期の対数値を
\[
Y_{ip}=\mu+\xi_i+\pi_p+\tau_{d(i,p)}+\varepsilon_{ip}
\]
とする（$\xi_i$：被験者効果，$\pi_p$：時期効果，$\tau_d$：製剤効果，$\varepsilon_{ip}\iid\Normal(0,\sigma_w^2)$，持ち越し効果なし）．
被験者ごとの差 $d_i=Y_i^T-Y_i^R$（T 投与時から R 投与時を引く）では被験者効果 $\xi_i$ が消え，
\[
\text{系列 TR：}\ d_i=(\tau_T-\tau_R)+(\pi_1-\pi_2)+e_i,\qquad
\text{系列 RT：}\ d_i=(\tau_T-\tau_R)-(\pi_1-\pi_2)+e_i
\]
（$e_i$ は2つの誤差の差で $\Normal(0,2\sigma_w^2)$）となる．
\begin{itemize}
\item 時期効果がなければ（$\pi_1=\pi_2$），$d_i\iid\Normal(\tau_T-\tau_R,2\sigma_w^2)$ で，$\bar d\pm t_{n-1}(0.05)\,s_d/\sqrt n$ はそのまま正しい90\%区間である．試験ではこの扱い（対応のある差の $t$ 区間）が用いられた．
\item 時期効果があっても系列の人数が等しければ（$n_1=n_2$），$\pm(\pi_1-\pi_2)$ が打ち消し合い $\bar d$ は $\tau_T-\tau_R$ の不偏推定量のままである．
      ただし $s_d^2$ に時期効果による系列間のばらつきが加わるので，区間はやや広く（保守的に）なる．
\item 時期効果を除いて推定するには，系列ごとの平均を等しい重みで平均した $\hat\tau=(\bar d_{TR}+\bar d_{RT})/2$ を用いる．
      $\V[\hat\tau]=\frac{2\sigma_w^2}{4}\bigl(\frac1{n_1}+\frac1{n_2}\bigr)=\frac{\sigma_w^2}{2}\bigl(\frac1{n_1}+\frac1{n_2}\bigr)$ で，$2\sigma_w^2$ を系列内でプールした $d_i$ の不偏分散で推定し，自由度 $n_1+n_2-2$ の $t$ 分布で区間を作る．
\end{itemize}
持ち越し効果は差 $d_i$ では消えないので，十分な休薬期間を設けてデザインで防ぐ．

\section{仮定}\label{sec:13-assump}
\begin{itemize}
\item 対数変換後の正規性（対数正規性），被験者の独立性．
\item クロスオーバー：持ち越し効果がない（十分な休薬期間），時期と製剤の交互作用がない．
\item 非劣性：マージンの事前設定．
\end{itemize}

\section{結果の解釈}\label{sec:13-interp}
\begin{itemize}
\item 「GMR の90\%CI $(0.98,1.13)$ が $(0.80,1.25)$ に含まれるので生物学的に同等」．
\item 「90\%CI $(0.86,1.29)$ は上限が1.25を超え，同等性は示されない」．この区間は1を含むので両側5\%の優越性検定も有意ではないが，それは同等の根拠にならない．
\item 非劣性：「95\%CI の下限 $-7.9\%$ がマージン $-10\%$ を上回るので非劣性が示された．上限が0を含むので優越性は示されない．」
\end{itemize}

\section{手法選択}\label{sec:13-choice}
\begin{itemize}
\item 後発品の生物学的同等性 → 対数変換，クロスオーバーの被験者ごとの差，90\%CI を $(0.80,1.25)$ と比較．
\item 新治療の有効性が標準治療に劣らないこと → 非劣性（95\%CI の下限とマージン）．
\item 差が両方向に小さいこと → 同等性（$(1-2\alpha)$ CI が $(-\Delta,\Delta)$ に含まれるか）．
\end{itemize}

\section{よくある誤り}\label{sec:13-err}
\begin{warnbox}
\begin{itemize}
\item 優越性検定の非有意を同等とみなす．
\item 同等性の判定に95\%CI を使う（片側5\%の2つの片側検定に対応するのは90\%CI）．
\item AUC を対数変換せずに比の区間を作る，または対数スケールの区間を指数変換し忘れる．
\item 境界付近で丸めた GMR の値で判定を誤る（対数スケールの区間端と $\pm0.2231$ を比べると確実）．
\end{itemize}
\end{warnbox}

\section{数理統計との接続}\label{sec:13-link}
\begin{linkbox}
\begin{itemize}
\item $t$ 区間の根拠は正規標本の $\bar X$ と不偏分散の独立性（『現代数理統計学の基礎』定理5.1）．
\item 信頼区間と検定の双対性：$\theta_0$ が $100(1-2\alpha)\%$ 区間の外にあることと，$\theta_0$ を帰無仮説の値とする片側 $\alpha$ の検定のどちらかが棄却されることは同値である．
\item \kakomonSM{2022}{5} の「対応のある2標本＝二元配置」はクロスオーバーの被験者効果の消去と同じ考え方である．
\end{itemize}
\end{linkbox}

\section{例題}\label{sec:13-ex}
\begin{reidai}[生物学的同等性]\label{reidai:13-1}
24名の2剤2期クロスオーバー試験（各系列12名）で，被験者ごとの $\log\mathrm{AUC}_T-\log\mathrm{AUC}_R$ の平均が $0.05$，標準偏差が $0.20$ であった．
時期効果はないものとし，$t_{23}(0.05)=1.714$，$\sqrt{24}=4.899$，$\log1.25=0.2231$ を用いよ．
\begin{enumerate}[label=(\arabic*)]
\item GMR の点推定値と90\%信頼区間を求め，生物学的同等性を判定せよ（$e^{0.05}=1.051$，$e^{-0.020}=0.980$，$e^{0.120}=1.127$）．
\item 標準偏差が $0.50$ であったら判定はどうなるか（$e^{-0.125}=0.882$，$e^{0.225}=1.252$）．
\end{enumerate}
\end{reidai}

\begin{reidai}[有意差なしと同等]\label{reidai:13-2}
8名の同様の試験で，平均 $0.05$，標準偏差 $0.30$ であった（$\sqrt8=2.828$，$t_7(0.05)=1.895$，$t_7(0.025)=2.365$，$e^{-0.151}=0.860$，$e^{0.251}=1.285$）．
\begin{enumerate}[label=(\arabic*)]
\item $H_0:\mu_T=\mu_R$ の両側5\%の $t$ 検定を行え．
\item 生物学的同等性を判定せよ．
\item (1)(2)の結果から何が言えるか．
\end{enumerate}
\end{reidai}

\section{解答}\label{sec:13-sol}
\begin{kaitou}{reidai:13-1}
(1) $\SE=0.20/\sqrt{24}=0.0408$．$0.05\pm1.714\times0.0408=0.05\pm0.070=(-0.020,0.120)$．
GMR $=e^{0.05}=1.05$，90\%CI $(0.980,1.127)\subset(0.80,1.25)$ で生物学的に同等．\\
(2) $\SE=0.50/4.899=0.1021$，$1.714\times0.1021=0.175$ で区間 $(-0.125,0.225)$．GMR では $(0.882,1.252)$．
上限 $0.225>0.2231$（$1.252>1.25$）なので同等とは言えない．点推定は同じでも，ばらつきが大きいと区間が広がり同等性を示せない．
\end{kaitou}

\begin{kaitou}{reidai:13-2}
(1) $\SE=0.30/\sqrt8=0.106$，$t=0.05/0.106=0.47$，$|t|<2.365$ で有意差なし．\\
(2) 90\%CI $0.05\pm1.895\times0.106=(-0.151,0.251)$ → $(0.860,1.285)$．上限が1.25を超え同等とは言えない．\\
(3) 有意差がないのは症例数が少なく推定が不正確だからであり，同等であることは示されない．「差があるとも同等とも言えない」が正しい結論．
\end{kaitou}

\begin{summarybox}
\begin{itemize}
\item 優越性 $H_0:\theta\le0$，非劣性 $H_0:\theta\le-\Delta$，同等性 $H_0:|\theta|\ge\Delta$．示したいことを対立仮説に．
\item 同等性：$(1-2\alpha)$CI $\subset(-\Delta,\Delta)$ で判定（各片側 $\alpha$ の2つの片側検定と同値）．
\item 非劣性：95\%CI 下限 $>-\Delta$．
\item BE：$\log$ 差の90\%CI を指数変換して $(0.80,1.25)$ に含まれれば同等．中央値 $e^\mu$ の比＝GMR．
\item クロスオーバー：被験者ごとの対数差で被験者効果が消え，対応のある $t$ 区間で扱える（系列が同数なら時期効果があっても $\bar d$ は不偏）．
\item 「有意差なし」≠「同等」．
\end{itemize}
\end{summarybox}
