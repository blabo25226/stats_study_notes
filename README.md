# 数理統計学 学習ノート
統計検定1級対策を起点に、数理統計学・医療統計学・測度論・確率過程・確率微分方程式までを、Obsidian上で問題・概念・復習履歴を関連付けて管理する学習リポジトリです。
## 目的
* 2026年11月の統計検定1級合格
* 将来の大学院入試に向けた数理統計学の学習

このリポジトリは、上記の目的を達成するための学習ノートをまとめたものです。数理統計学に加え、測度論、確率論、確率過程論、確率微分方程式へと学習範囲を広げていきます。
[Obsidian](https://obsidian.md/) のVaultとして閲覧・整理し、Gitで管理しています。

## Obsidianでの使い方

1. このリポジトリのルートをVaultとして開きます。
2. [00_学習管理/Home.md](00_学習管理/Home.md)（学習ダッシュボード）から始めます。
3. 学習ロードマップは `00_学習管理/MOC/`、問題一覧・復習管理は `00_学習管理/Bases/` にあります。

コミュニティプラグインは不要で、コアプラグイン（Bases、Daily notes、Templates など）のみで動作します。

## ノートの形式

- 問題ノートは1問1ファイルで、本文は「問題の要約」と「答案」のみです。
- 採点結果はfrontmatterの `status`（正解／部分的なミスあり／不正解／回答なし）で表し、復習状態は `review-count`・`last-reviewed`・`next-review` で管理します。
- 関連する概念ノートへのリンクは、frontmatterの `concepts` で表します。
- 詳細な規則は [.agents/rules/frontmatter.md](.agents/rules/frontmatter.md) を参照してください。

## 公開範囲と著作権

教科書のスクリーンショット、手書き答案の写真、公式解答PDFなどの教材は著作権や個人情報の観点からGit管理の対象外です。以下は `.gitignore` によりローカル専用です。

- `90_data/`、`91_docs/`、`92_src/`、`93_scratch/`
- `daily_report.md`（AI作業ログ）

問題文は転載せず、要約のみを記載します。方針は [.agents/rules/copyright.md](.agents/rules/copyright.md) に従います。

## AIアシスタントの利用

教材処理・採点・Vault整理にAI（Claude Code、Gemini）を使っています。共通ルールは [AGENTS.md](AGENTS.md) と `.agents/`、Claude専用のVault管理ルールは `.claude/` にあります。AIはGit commit / pushを自動では行いません。
