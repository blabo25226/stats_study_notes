# 学習管理

このフォルダは学習コンテンツそのものではなく、Obsidian上での管理UIを置く。

```text
00_学習管理/
├── Home.md
├── Bases/
├── MOC/
├── Daily/
└── Templates/
```

## 役割

- `Home.md`: Vaultの入口
- `Bases/`: Propertiesを使った一覧・復習管理
- `MOC/`: 学習分野の目次・ロードマップ
- `Daily/`: 日々の学習記録
- `Templates/`: Obsidian Templates用

ルートの `daily_report.md` はAI作業ログであり、このフォルダのDailyとは別用途。
