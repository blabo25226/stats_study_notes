## 解答の書き方

1. **条件**：母数範囲、密度の台、独立性、収束の種類。
2. **導出**：積分・変数変換・期待値の計算を省略しない。
3. **検算**：正規化 $1$、分散非負、境界での挙動。
4. **適用**：ノート中の「過去問に対応するオリジナル例題」に自力で取り組み、その後に解答を開く。

過去問の原文・解答を公開ノートに転載せず、対応する**年度・科目・問番号**のみ参照している。公式問題・公式解答は共有済みの非公開教材側で確認する。
