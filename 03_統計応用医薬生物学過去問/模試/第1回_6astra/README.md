## ソースと再生成

3冊のPDFそれぞれに同名の `.tex` があります。共通設定は `sa_mock_style.tex` です。
LuaLaTeXと `ltjsarticle` が利用できる環境で、このフォルダから次を実行します。

```powershell
python build.py
```

補助ファイルはリポジトリの `93_scratch/sa_mock1_build/` に生成されます。
数値検算はPythonのNumPy・SciPy・SymPyを使い、次で再実行できます。

```powershell
python verify_math.py
```

これは作成者用の検算であり、受験時にPythonや関数電卓を使う必要はありません。
