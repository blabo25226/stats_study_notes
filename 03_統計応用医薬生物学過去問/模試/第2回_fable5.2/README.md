## ソースと再生成

各PDFと同名の `.tex`、共通設定 `sa_mock_style.tex` を同梱しています。このフォルダで次を実行します。

```powershell
python build.py        # LuaLaTeX（ltjsarticle）で3冊を各2回コンパイル
python verify_math.py  # NumPy・SciPy・SymPy による検算（乱数シード固定）
```

- `build.py` は日本語ファイル名の処理を安定させるため、`93_scratch/sa_mock2_build/` に英数字名でコピーしてコンパイルし、PDFをこのフォルダへ戻します。補助ファイルは `93_scratch/` に残ります。
- 問題冊子は各大問を1ページに収めるため10pt、模範解答と採点基準は11ptで組んでいます。
- `verify_math.py` は模範解答のTeXを読まず、問題文のデータ・モデルから再計算して照合します。作成者用の検算であり、受験時にPythonは不要です。
