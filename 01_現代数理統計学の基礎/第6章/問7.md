# 第6章 問7

## 問題の要約

$X \mid p \sim \mathrm{Bin}(n, p)$、事前分布として $p \sim \mathrm{Beta}(\alpha, \beta)$ を考える。
1. $p$ の事後分布が $\mathrm{Beta}(X+\alpha, n - X + \beta)$ となることを示せ。
2. 二乗誤差損失のもとでの $p$ のベイズ推定量 $\hat{p}_B$ が、最尤推定量 $\frac{X}{n}$ と事前平均 $\frac{\alpha}{\alpha+\beta}$ の重み付き平均（凸結合）
   $$
   \hat{p}_B = \frac{n}{\alpha+\beta+n} \frac{X}{n} + \frac{\alpha+\beta}{\alpha+\beta+n} \frac{\alpha}{\alpha+\beta}
   $$
   として表されることを示せ。

## 答案

### (1)

事後分布の密度関数 $\pi(p \mid X)$ は、ベイズの定理より尤度と事前分布の積に比例する：
$$
\pi(p \mid X) \propto f(X \mid p) \pi(p)
$$
$$
\propto p^X (1 - p)^{n - X} \cdot p^{\alpha - 1} (1 - p)^{\beta - 1} = p^{X + \alpha - 1} (1 - p)^{n - X + \beta - 1}
$$
これはパラメータ $X + \alpha, n - X + \beta$ のベータ分布 $\mathrm{Beta}(X + \alpha, n - X + \beta)$ の核（kernel）である。したがって、
$$
p \mid X \sim \mathrm{Beta}(X + \alpha, n - X + \beta)
$$
が示された。

### (2)

二乗誤差損失のもとでのベイズ推定量 $\hat{p}_B$ は事後平均 $\mathrm{E}[p \mid X]$ で与えられる。
(1) より $p \mid X \sim \mathrm{Beta}(X+\alpha, n-X+\beta)$ であるから、ベータ分布の期待値の公式より、
$$
\hat{p}_B = \mathrm{E}[p \mid X] = \frac{X + \alpha}{(X + \alpha) + (n - X + \beta)} = \frac{X + \alpha}{\alpha + \beta + n} \quad \cdots (1)
$$
一方、問題で与えられた表示式を整理すると、
$$
\frac{n}{\alpha + \beta + n} \cdot \frac{X}{n} + \frac{\alpha + \beta}{\alpha + \beta + n} \cdot \frac{\alpha}{\alpha + \beta} = \frac{X}{\alpha + \beta + n} + \frac{\alpha}{\alpha + \beta + n} = \frac{X + \alpha}{\alpha + \beta + n}
$$
となり、これは $(1)$ と一致する。
したがって、ベイズ推定量が最尤推定量と事前平均の重み付き平均として表されることが示された。

## 採点・解説

**判定**: 正解

共役事前分布としてのベータ分布の性質を用いた事後分布の導出、および二乗誤差損失におけるベイズ推定量（事後期待値）の計算が正確に行われている。さらに標本情報（最尤推定量）と事前情報（事前期待値）の重み付き平均としての解釈も明快に示されている。
