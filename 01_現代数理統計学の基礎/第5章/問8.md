# 第5章 問8

## 問題の要約

独立同分布な確率変数列 $X_1, X_2, \dots$（平均 $\mu$、分散 $\sigma^2 < \infty$）に対し、重み付き平均 $W_n = \frac{2}{n(n+1)} \sum_{j=1}^n j X_j$ が $\mu$ に確率収束することを示せ。

### 数学的解説
平均自乗収束を示せば、チェビシェフの不等式より確率収束が従う。
$\sum_{j=1}^n j = \frac{n(n+1)}{2}$ であるから、$E[W_n] = \frac{2}{n(n+1)} \sum_{j=1}^n j E[X_j] = \mu$ であり、$W_n$ は不偏推定量である。
分散を計算すると、$X_j$ の独立性より
$$
\mathrm{Var}(W_n) = \left(\frac{2}{n(n+1)}\right)^2 \sum_{j=1}^n j^2 \mathrm{Var}(X_j) = \frac{4\sigma^2}{n^2(n+1)^2} \sum_{j=1}^n j^2
$$
ここで $\sum_{j=1}^n j^2 = \frac{n(n+1)(2n+1)}{6}$ を代入すると、
$$
\mathrm{Var}(W_n) = \frac{4\sigma^2}{n^2(n+1)^2} \frac{n(n+1)(2n+1)}{6} = \frac{2(2n+1)\sigma^2}{3n(n+1)} = O\left(\frac{1}{n}\right) \to 0 \quad (n \to \infty)
$$
平均自乗収束 $E[(W_n - \mu)^2] \to 0$ より、$W_n \xrightarrow{p} \mu$ が示される。
