# 第5章 問1

## 問題の要約

正規母集団 $N(\mu, \sigma^2)$ からの無作為標本 $X_1, \dots, X_n$ に対し、標本平均 $\bar{X}$ と標本分散 $S^2 = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2$ を考える。統計量 $\bar{X} + \sqrt{n}S$ の平均と分散を求めよ。

### 数学的解説
定理5.1より、正規標本において $\bar{X}$ と $S^2$ は互いに独立に分布する。
標準化変数 $Z = \frac{\sqrt{n}(\bar{X} - \mu)}{\sigma} \sim N(0, 1)$、および $Y = \frac{nS^2}{\sigma^2} \sim \chi^2_{n-1}$ とおくと、$Z$ と $Y$ は独立である。
これらを用いると、
$$
\bar{X} + \sqrt{n}S = \left(\mu + \frac{\sigma}{\sqrt{n}} Z\right) + \sigma \sqrt{Y} = \mu + \frac{\sigma}{\sqrt{n}} Z + \sigma \sqrt{Y}
$$
と表せる。

#### 1. 平均の計算
$E[Z] = 0$ であり、$Y \sim \chi^2_{n-1}$ の平方根の期待値は第3章問18より、
$$
C = E[\sqrt{Y}] = \sqrt{2} \frac{\Gamma(n/2)}{\Gamma((n-1)/2)}
$$
となる。したがって、
$$
E[\bar{X} + \sqrt{n}S] = \mu + \sigma C = \mu + \sqrt{2}\sigma \frac{\Gamma(n/2)}{\Gamma((n-1)/2)}
$$

#### 2. 分散の計算
$Z$ と $Y$ は独立であるため共分散は0であり、
$$
\mathrm{Var}(\bar{X} + \sqrt{n}S) = \mathrm{Var}\left(\frac{\sigma}{\sqrt{n}} Z\right) + \mathrm{Var}(\sigma \sqrt{Y}) = \frac{\sigma^2}{n} + \sigma^2 (E[Y] - (E[\sqrt{Y}])^2)
$$
ここで $E[Y] = n-1$ であるから、
$$
\mathrm{Var}(\bar{X} + \sqrt{n}S) = \frac{\sigma^2}{n} + \sigma^2 (n - 1 - C^2)
$$
となる。
