# 第5章 問16

## 問題の要約

確率密度関数 $f(x) = \frac{a}{\theta^a} x^{a-1} I(0 < x < \theta)$ ($a > 0$) からの無作為標本 $X_1, \dots, X_n$ の順序統計量を $X_{(1)} \le \dots \le X_{(n)}$ とする。
(1) $U_n = X_{(n)}$, $U_{n-1} = X_{(n-1)}/X_{(n)}$, ..., $U_1 = X_{(1)}/X_{(2)}$ の同時確率密度関数を求めよ。
(2) 適切な数列 $a_n > 0, b_n$ を選ぶことで、$\frac{U_n - b_n}{a_n}$ の極限分布を求めよ。

## 答案

### (1)
$X_{(n)} = U_n$, $X_{(n-1)} = U_n U_{n-1}$, ..., $X_{(1)} = U_n U_{n-1} \dots U_1$。
変数変換のヤコビアンは下三角行列の行列式となり、
$$
J = U_n^{n-1} U_{n-1}^{n-2} \dots U_2
$$
順序統計量の同時密度関数は
$$
f_{X_{(1)}, \dots, X_{(n)}}(x_1, \dots, x_n) = n! \left(\frac{a}{\theta^a}\right)^n \prod_{i=1}^n x_i^{a-1}
$$
各 $x_i$ を $u$ で表して代入すると、
$$
\begin{aligned}
f_{U_1, \dots, U_n}(u_1, \dots, u_n) &= n! \left(\frac{a}{\theta^a}\right)^n (u_n u_{n-1}\dots u_1)^{a-1} (u_n \dots u_2)^{a-1} \dots u_n^{a-1} \cdot u_n^{n-1} u_{n-1}^{n-2} \dots u_2 \\
&= n! \left(\frac{a}{\theta^a}\right)^n u_1^{a-1} u_2^{2a-1} \dots u_n^{na-1} \quad (0 < u_i < 1 \; (i < n), \; 0 < u_n < \theta)
\end{aligned}
$$

### (2)
$X$ の累積分布関数は $F_X(x) = \int_0^x \frac{a}{\theta^a} t^{a-1} dt = \left(\frac{x}{\theta}\right)^a$ ($0 < x < \theta$)。
最大統計量 $U_n = X_{(n)}$ の分布関数は
$$
F_{X_{(n)}}(x) = \{F_X(x)\}^n = \left(\frac{x}{\theta}\right)^{an}
$$
$P\left(\frac{U_n - b_n}{a_n} \le u\right) = P(U_n \le a_n u + b_n) = \theta^{-an} (a_n u + b_n)^{an} = \left(\frac{a_n u + b_n}{\theta}\right)^{an}$。
ここで $a_n = \frac{\theta}{n}, b_n = \theta$ とおくと、$u < 0$ に対し
$$
P\left(\frac{U_n - \theta}{\theta/n} \le u\right) = \left(1 + \frac{u}{n}\right)^{an} = \left\{\left(1 + \frac{u}{n}\right)^n\right\}^a \xrightarrow{n \to \infty} e^{au}
$$
となる。
