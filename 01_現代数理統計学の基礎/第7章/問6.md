# 第7章 問6

## 問題の要約

$X_1, \dots, X_n \stackrel{\mathrm{i.i.d.}}{\sim} N(0, \sigma_X^2)$、$Y_1, \dots, Y_m \stackrel{\mathrm{i.i.d.}}{\sim} N(0, \sigma_Y^2)$ とし、2つの標本は互いに独立とする。$\lambda = \sigma_Y^2 / \sigma_X^2$ とし、$\lambda_0$ は既知とする。

(1) $H_0: \lambda = \lambda_0$ vs $H_1: \lambda \neq \lambda_0$ に対する有意水準 $\alpha$ の尤度比検定を求める。
(2) この検定の棄却域を $F$ 統計量に基づいて記す。

## 答案

$X_1, \dots, X_n \stackrel{\mathrm{i.i.d.}}{\sim} N(0, \sigma_X^2)$
$Y_1, \dots, Y_m \stackrel{\mathrm{i.i.d.}}{\sim} N(0, \sigma_Y^2)$
$X, Y$ は独立し、$\lambda = \frac{\sigma_Y^2}{\sigma_X^2}$ とし、$\lambda_0$ は既知である。

(1)
$H_0: \lambda = \lambda_0, H_1: \lambda \neq \lambda_0$ について有意水準 $\alpha$ の尤度比検定を与える。

$L(\sigma_X^2, \sigma_Y^2 \mid \bm{x}, \bm{y}) = \prod_{i=1}^n \frac{1}{\sqrt{2\pi\sigma_X^2}} \exp\left(-\frac{x_i^2}{2\sigma_X^2}\right) \prod_{j=1}^m \frac{1}{\sqrt{2\pi\sigma_Y^2}} \exp\left(-\frac{y_j^2}{2\sigma_Y^2}\right)$
$= (2\pi)^{-\frac{n+m}{2}} (\sigma_X^2)^{-\frac{n}{2}} (\sigma_Y^2)^{-\frac{m}{2}} \exp\left(-\frac{\sum x_i^2}{2\sigma_X^2} - \frac{\sum y_j^2}{2\sigma_Y^2}\right)$

ここで $\lambda, \sigma^2 (= \sigma_X^2)$ を未知母数とし、$H_0$ で $\lambda_0, \sigma^2$ を既知母数として与える。
なお、$\sigma^2$ は $H_0$ のもとで定義され、
$L(\lambda, \sigma^2 \mid \bm{x}, \bm{y}) = (2\pi)^{-\frac{n+m}{2}} (\sigma^2)^{-\frac{n+m}{2}} \lambda^{-\frac{m}{2}} \exp\left(-\frac{\sum x_i^2}{2\sigma^2} - \frac{\sum y_j^2}{2\sigma^2\lambda}\right)$
$l(\lambda, \sigma^2 \mid \bm{x}, \bm{y}) = -\frac{n+m}{2}\log(2\pi) - \frac{n+m}{2}\log\sigma^2 - \frac{m}{2}\log\lambda - \frac{1}{2\sigma^2}\sum x_i^2 - \frac{1}{2\sigma^2\lambda}\sum y_j^2$
つまり
$\frac{\partial l(\lambda_0, \sigma^2)}{\partial \sigma^2} = -\frac{n+m}{2\sigma^2} + \frac{1}{2\sigma^4}\left(\sum x_i^2 + \frac{1}{\lambda_0}\sum y_j^2\right) = 0$
$\therefore \hat{\sigma}_0^2 = \frac{1}{n+m}\left(\sum_{i=1}^n x_i^2 + \frac{1}{\lambda_0}\sum_{j=1}^m y_j^2\right)$ となる。

$H_1$ では
$\frac{\partial l}{\partial \sigma_X^2} = 0 \implies \hat{\sigma}_X^2 = \frac{1}{n}\sum_{i=1}^n x_i^2$
$\frac{\partial l}{\partial \sigma_Y^2} = 0 \implies \hat{\sigma}_Y^2 = \frac{1}{m}\sum_{j=1}^m y_j^2$
$\hat{\lambda} = \frac{\hat{\sigma}_Y^2}{\hat{\sigma}_X^2}, \hat{\sigma}^2 = \hat{\sigma}_X^2$ より

$\Lambda(\bm{x}, \bm{y}) = \frac{L(\lambda_0, \hat{\sigma}_0^2 \mid \bm{x}, \bm{y})}{L(\hat{\lambda}, \hat{\sigma}_X^2 \mid \bm{x}, \bm{y})} = \frac{(2\pi)^{-\frac{n+m}{2}} (\hat{\sigma}_0^2)^{-\frac{n+m}{2}} \lambda_0^{-\frac{m}{2}} \exp\left(-\frac{\sum x_i^2}{2\hat{\sigma}_0^2} - \frac{\sum y_j^2}{2\hat{\sigma}_0^2\lambda_0}\right)}{(2\pi)^{-\frac{n+m}{2}} (\hat{\sigma}_X^2)^{-\frac{n+m}{2}} \hat{\lambda}^{-\frac{m}{2}} \exp\left(-\frac{\sum x_i^2}{2\hat{\sigma}_X^2} - \frac{\sum y_j^2}{2\hat{\sigma}_X^2\hat{\lambda}}\right)}$

ここで $\sum x_i^2 = n\hat{\sigma}_X^2, \sum y_j^2 = m\hat{\sigma}_Y^2 = m\frac{\hat{\sigma}_Y^2}{\hat{\sigma}_X^2}\hat{\sigma}_X^2 = m\hat{\lambda}\hat{\sigma}_X^2$
$\hat{\sigma}_0^2 = \frac{n\hat{\sigma}_X^2}{n+m} + \frac{m\frac{\hat{\lambda}}{\lambda_0}\hat{\sigma}_X^2}{n+m}$ より

$\Lambda(\bm{x}, \bm{y}) = \left(\frac{n}{n+m} + \frac{m}{n+m}\frac{\hat{\lambda}}{\lambda_0}\right)^{-\frac{n+m}{2}} \left(\frac{\lambda_0}{\hat{\lambda}}\right)^{\frac{m}{2}} \exp\left(-\frac{n\hat{\sigma}_X^2}{2\hat{\sigma}_0^2} - \frac{m\hat{\sigma}_Y^2}{2\hat{\sigma}_0^2\lambda_0} + \frac{n}{2} + \frac{m}{2}\right)$
$= \left(\frac{n}{n+m} + \frac{m}{n+m}\frac{\hat{\lambda}}{\lambda_0}\right)^{-\frac{n+m}{2}} \left(\frac{\lambda_0}{\hat{\lambda}}\right)^{\frac{m}{2}} \exp\left(-\frac{n}{2}\cdot\frac{1}{\frac{n}{n+m}+\frac{m}{n+m}\frac{\hat{\lambda}}{\lambda_0}} - \frac{m}{2\lambda_0}\cdot\frac{\frac{\hat{\lambda}}{\lambda_0}}{\frac{n}{n+m}+\frac{m}{n+m}\frac{\hat{\lambda}}{\lambda_0}} + \frac{n}{2} + \frac{m}{2}\right)$
$= \left(\frac{n}{n+m} + \frac{m}{n+m}\frac{\hat{\lambda}}{\lambda_0}\right)^{-\frac{n+m}{2}} \left(\frac{\lambda_0}{\hat{\lambda}}\right)^{\frac{m}{2}} \exp\left(-\frac{n(n+m)}{2(n+m\frac{\hat{\lambda}}{\lambda_0})} - \frac{m(n+m)}{2\lambda_0(n+m\frac{\hat{\lambda}}{\lambda_0})} + \frac{n}{2} + \frac{m}{2}\right)$

$-2\log\Lambda(\bm{x}) = (n+m)\log\left(\frac{n}{n+m} + \frac{m}{n+m}\frac{\hat{\lambda}}{\lambda_0}\right) + m\log\frac{\hat{\lambda}}{\lambda_0} + \frac{n(n+m)}{n+m\frac{\hat{\lambda}}{\lambda_0}} + \frac{m(n+m)}{\lambda_0(n+m\frac{\hat{\lambda}}{\lambda_0})} - n - \frac{m}{\lambda_0^2}$
$\sim \chi^2_1$ より
$R = \left\{ \bm{x} \in \mathcal{X}, \bm{y} \in \mathcal{Y} \;\middle|\; (n+m)\log\left(\frac{n}{n+m} + \frac{m}{n+m}\frac{\hat{\lambda}}{\lambda_0}\right) + m\log\frac{\hat{\lambda}}{\lambda_0} + \frac{n(n+m)}{n+m\frac{\hat{\lambda}}{\lambda_0}} + \frac{m(n+m)}{\lambda_0(n+m\frac{\hat{\lambda}}{\lambda_0})} - n - \frac{m}{\lambda_0^2} > \chi^2_{1, \alpha} \right\}$

(2)
$\hat{\lambda} = F$ とおく $(F \sim F_{m, n})$ より
$R = \left\{ \bm{x} \in \mathcal{X}, \bm{y} \in \mathcal{Y} \;\middle|\; (n+m)\log\left(\frac{n}{n+m} + \frac{m}{n+m}\frac{F}{\lambda_0}\right) + m\log\frac{F}{\lambda_0} + \frac{n(n+m)}{n+m\frac{F}{\lambda_0}} + \frac{m(n+m)}{\lambda_0(n+m\frac{F}{\lambda_0})} - n - \frac{m}{\lambda_0^2} > \chi^2_{1, \alpha} \right\}$
