# 第7章 問8

## 問題の要約

$X_1, \dots, X_n \stackrel{\mathrm{i.i.d.}}{\sim} f(x \mid \alpha, \beta) = \frac{\beta\alpha^\beta}{x^{\beta+1}} \; (x > \alpha, \alpha > 0, \beta > 0)$ とする。

(1) $(\alpha, \beta)$ に対する十分統計量を求める。
(2) $\alpha, \beta$ の最尤推定量を求める。
(3) 仮説 $H_0: \beta = 1$ vs $H_1: \beta \neq 1$ に対する尤度比検定を $T = \log\left\{\prod_{i=1}^n X_i / (\min_i X_i)^n\right\}$ を用いて与える。

## 答案

$X_1, \dots, X_n \stackrel{\mathrm{i.i.d.}}{\sim} \mathrm{Pareto}(\alpha, \beta)$

(1)
$f_X(x \mid \alpha, \beta) = \frac{\beta\alpha^\beta}{x^{\beta+1}}, \quad \alpha < x, \alpha > 0, \beta > 0$
$L(\alpha, \beta \mid \bm{x}) = \prod_{i=1}^n \frac{\beta\alpha^\beta}{x_i^{\beta+1}} I(\alpha < x_i) = \frac{\beta^n \alpha^{n\beta}}{(x_1 \cdots x_n)^{\beta+1}} I(\alpha < x_{(1)})$
より $T_\alpha(\bm{X}) = X_{(1)}, \quad T_\beta(\bm{X}) = \prod_{i=1}^n X_i$

(2)
$L(\alpha, \beta \mid \bm{x}) = \frac{\beta^n \alpha^{n\beta}}{(x_1 \cdots x_n)^{\beta+1}} I(\alpha < x_{(1)})$
$\alpha$ について尤度関数は $\alpha < x_{(1)}$ のとき $L(\alpha) \propto \alpha^{n\beta}, n\beta > 0$ より単調増加するため $\hat{\alpha} = X_{(1)}$
$L(\beta \mid \bm{x}) = \frac{\beta^n \alpha^{n\beta}}{(x_1 \cdots x_n)^{\beta+1}}$
$l(\beta \mid \bm{x}) = n\log\beta + n\beta\log\alpha - (\beta+1)\sum_{i=1}^n \log x_i$
$\frac{\partial l}{\partial \beta} = \frac{n}{\beta} + n\log\alpha - \sum_i \log x_i = 0$
$\frac{n}{\beta} = \sum \log X_i - n\log\alpha$
$\hat{\beta} = \frac{n}{\sum \log X_i - n\log X_{(1)}}$

(3)
$H_0: \beta = 1, H_1: \beta \neq 1$ の尤度比検定を $T = \log\left(\frac{\prod X_i}{X_{(1)}^n}\right)$ で与える。
(2)より
$\Lambda(\bm{x}) = \frac{L(\hat{\alpha}, 1 \mid \bm{x})}{L(\hat{\alpha}, \hat{\beta} \mid \bm{x})} = \frac{\frac{\hat{\alpha}^n}{(x_1 \cdots x_n)^2}}{\frac{\hat{\beta}^n \hat{\alpha}^{n\hat{\beta}}}{(x_1 \cdots x_n)^{\hat{\beta}+1}}}$
$= \hat{\alpha}^{n(1-\hat{\beta})} \hat{\beta}^{-n} (x_1 \cdots x_n)^{\hat{\beta}-1}, \quad \hat{\beta} = \frac{n}{\sum \log\frac{X_i}{X_{(1)}}} = \frac{n}{T}$ より
$= X_{(1)}^{n(1-\frac{n}{T})} \left(\frac{n}{T}\right)^{-n} (x_1 \cdots x_n)^{\frac{n}{T}-1}$
$= \left(\frac{x_1 \cdots x_n}{X_{(1)}^n}\right)^{\frac{n}{T}-1} \left(\frac{n}{T}\right)^{-n}$
$= e^{T \cdot (\frac{n}{T} - 1)} \left(\frac{n}{T}\right)^{-n}$
$= e^{n-T} \left(\frac{T}{n}\right)^n$ となる。
よって検定は $R = \left\{ \bm{x} \in \mathcal{X} \;\middle|\; \exp(n-T)\left(\frac{T}{n}\right)^n > c \right\}$
