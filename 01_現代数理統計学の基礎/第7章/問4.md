# 第7章 問4

## 問題の要約

$X_1, \dots, X_n \stackrel{\mathrm{i.i.d.}}{\sim} Ex(\lambda)$ とし、$\lambda_0$ を既知とする。

(1) $H_0: \lambda \le \lambda_0$ vs $H_1: \lambda > \lambda_0$ なる仮説検定に対する尤度比検定を求める。
(2) $H_0$ のもとでの分布を求め、有意水準 $\alpha$ の棄却域を構成する。
(3) この検定手法の検出力を計算する。

## 答案

$X_1, \dots, X_n \stackrel{\mathrm{i.i.d.}}{\sim} Ex(\lambda)$、$\lambda_0$ は既知とする。

(1)
$H_0: \lambda \le \lambda_0$, $H_1: \lambda > \lambda_0$ の尤度比検定を与える。
$L(\lambda, \bm{x}) = \lambda^n \exp\left(-\lambda \sum_{i=1}^n x_i\right) = \lambda^n \exp(-n\lambda\bar{x})$
$l(\lambda \mid \bm{x}) = n\log\lambda - n\lambda\bar{x}$
$\frac{\partial l}{\partial \lambda} = \frac{n}{\lambda} - n\bar{x} \implies \hat{\lambda} = \frac{1}{\bar{x}}$ となる。

$\bar{x} \le \lambda_0$ ならば $\hat{\lambda}_0 = \frac{1}{\bar{x}}, \Lambda(\bm{x}) = 1$
$\lambda_0 < \bar{x}$ ならば $\hat{\lambda}_0 = \lambda_0$
$\Lambda(\bm{x}) = \frac{L(\lambda_0, \bm{x})}{L(\frac{1}{\bar{x}}, \bm{x})} = \frac{\lambda_0^n \exp(-n\lambda_0\bar{x})}{\bar{x}^{-n} \exp\left(-n\frac{1}{\bar{x}}\bar{x}\right)} = (\lambda_0\bar{x})^n \exp(-n\lambda_0\bar{x} + n)$
よって
$R = \{ \bm{x} \in \mathcal{X} \mid (\lambda_0\bar{x}) < c \}$

(2)
$\bar{X} \sim N\left(\lambda, \frac{\lambda}{n}\right)$ より
$\sqrt{n}\frac{\bar{X} - \lambda_0}{\sqrt{\lambda_0}} \sim N(0, 1)$
$\therefore R = \left\{ \bm{x} \in \mathcal{X} \;\middle|\; \left|\sqrt{n}\frac{\bar{x} - \lambda_0}{\sqrt{\lambda_0}}\right| \ge z_{\frac{\alpha}{2}} \right\}$
