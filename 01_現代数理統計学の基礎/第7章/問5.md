# 第7章 問5

## 問題の要約

$X_1, \dots, X_n \stackrel{\mathrm{i.i.d.}}{\sim} Po(\lambda)$ とし、$\lambda_0$ を既知とする。このとき $H_0: \lambda = \lambda_0$ vs $H_1: \lambda \neq \lambda_0$ なる仮説検定に対する尤度比検定、ワルド検定、スコア検定を求める。

## 答案

$X_1, \dots, X_n \stackrel{\mathrm{i.i.d.}}{\sim} Po(\lambda)$、$\lambda_0$ は既知とする。
$H_0: \lambda = \lambda_0, H_1: \lambda \neq \lambda_0$ を尤度比、ワルド、スコア検定で与える。

(i) 尤度比検定
$L(\lambda \mid \bm{x}) = \prod_{i=1}^n \frac{\lambda^{x_i} e^{-\lambda}}{x_i!} = \frac{\lambda^{\sum x_i} e^{-n\lambda}}{x_1! \cdots x_n!}$
$l(\lambda \mid \bm{x}) = n\bar{x}\log\lambda - n\lambda - \sum \log(x_i!)$
$\frac{\partial l}{\partial \lambda} = \frac{n\bar{x}}{\lambda} - n = 0 \implies \hat{\lambda} = \bar{x}$
よって
$\Lambda(\bm{x}) = \frac{L(\lambda_0, \bm{x})}{L(\bar{x}, \bm{x})} = \frac{\frac{\lambda_0^{n\bar{x}} e^{-n\lambda_0}}{x_1! \cdots x_n!}}{\frac{\bar{x}^{n\bar{x}} e^{-n\bar{x}}}{x_1! \cdots x_n!}} = \left(\frac{\lambda_0}{\bar{x}}\right)^{n\bar{x}} \exp(n\bar{x} - n\lambda_0)$
$-2\log\Lambda(\bm{x}) = -2n\bar{x}\log\frac{\lambda_0}{\bar{x}} + 2n\lambda_0 - 2n\bar{x} \sim \chi^2_1$
よって
$R = \left\{ \bm{x} \in \mathcal{X} \;\middle|\; -2n\left(\bar{x}\left(\log\frac{\lambda_0}{\bar{x}} + 1\right) - \lambda_0\right) > \chi^2_{1, \alpha} \right\}$

(ii) ワルド検定
$\hat{\lambda} = \bar{x}, V(\bar{X}) = \frac{\lambda}{n}$ より
検定統計量は
$\frac{\bar{X} - \lambda}{\sqrt{\bar{X}/n}} \sim N(0, 1)$ となる。
よって
$R = \left\{ \bm{x} \in \mathcal{X} \;\middle|\; \left|\sqrt{n}\frac{\bar{x} - \lambda}{\sqrt{\bar{x}}}\right| > z_{\frac{\alpha}{2}} \right\}$

(iii) スコア検定
$\frac{\partial l}{\partial \lambda} = \frac{n\bar{x}}{\lambda} - n$
$\frac{\partial^2 l}{\partial \lambda^2} = -\frac{n\bar{x}}{\lambda^2} \implies I_n(\lambda) = E\left[-\frac{\partial^2 l}{\partial \lambda^2}\right] = \frac{n}{\lambda^2}E[\bar{X}] = \frac{n}{\lambda}$
よって
$\frac{\frac{n}{\lambda}\bar{x} - n}{\sqrt{n/\lambda}} = \sqrt{\frac{n}{\lambda}}\bar{x} - \sqrt{\frac{n}{\lambda}}\cdot \lambda = \sqrt{\frac{n}{\lambda}}\bar{x} - \sqrt{n\lambda} \sim N(0, 1)$
$\therefore R = \left\{ \bm{x} \in \mathcal{X} \;\middle|\; \left|\sqrt{n}\frac{\bar{x} - \lambda}{\sqrt{\lambda}}\right| > z_{\frac{\alpha}{2}} \right\}$
