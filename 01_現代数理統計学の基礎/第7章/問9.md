# 第7章 問9

## 問題の要約

$X_1, \dots, X_n \stackrel{\mathrm{i.i.d.}}{\sim} Ex(\lambda)$ とし、$\lambda_0, \lambda_1 \; (\lambda_1 > \lambda_0)$ を既知とする。

(1) $H_0: \lambda = \lambda_0$ vs $H_1: \lambda = \lambda_1$ なる仮説検定に対する有意水準 $\alpha$ の最強力検定を求める。
(2) $H_0: \lambda \le \lambda_0$ vs $H_1: \lambda > \lambda_0$ なる仮説検定に対する一様最強力検定を与える。

## 答案

$X_1, \dots, X_n \stackrel{\mathrm{i.i.d.}}{\sim} Ex(\lambda)$

(1)
$H_0: \lambda = \lambda_0, H_1: \lambda = \lambda_1$
$\lambda_0 < \lambda_1$ に対する有意水準 $\alpha$ の最強力検定を与える。
$L(\lambda, \bm{x}) = \lambda^n e^{-\lambda \sum x_i}$
$\Lambda(\bm{x}) = \frac{L(\lambda_0, \bm{x})}{L(\lambda_1, \bm{x})} = \frac{\lambda_0^n e^{-\lambda_0 \sum x_i}}{\lambda_1^n e^{-\lambda_1 \sum x_i}} = \left(\frac{\lambda_0}{\lambda_1}\right)^n \exp\left(-(\lambda_0 - \lambda_1)\sum x_i\right)$
よって
$R = \left\{ \bm{x} \in \mathcal{X} \;\middle|\; \left(\frac{\lambda_0}{\lambda_1}\right)^n \exp\left(-(\lambda_0 - \lambda_1)\sum x_i\right) > c \right\}$
で検定は与えられる。
これは実質的に $\sum X_i$ の検定である。

$M_X(t) = E[e^{tX}] = \int_0^\infty \lambda e^{(t-\lambda)x} dx = \left[ \frac{\lambda}{t-\lambda} e^{(t-\lambda)x} \right]_0^\infty = \frac{\lambda}{t-\lambda}(0-1) \quad (t-\lambda < 0) = \frac{\lambda}{\lambda - t} \quad (t < \lambda \text{ でもよい})$
$M_{\sum X_i}(t) = \frac{\lambda^n}{(\lambda - t)^n} = \left(\frac{1}{1 - \frac{t}{\lambda}}\right)^n$ より $\sum X_i \sim Ga\left(n, \frac{1}{\lambda}\right)$

$H_0$ のもとで $\sum X_i \sim Ga\left(n, \frac{1}{\lambda_0}\right)$
よって $2\lambda_0 \sum X_i \sim \chi^2_{2n}$ となる。
したがって
$R = \left\{ \bm{x} \in \mathcal{X} \;\middle|\; 2\lambda_0 \sum x_i \ge \chi^2_{2n, \alpha} \right\}$

(2)
$H_0: \lambda \le \lambda_0, H_1: \lambda > \lambda_0$ に対し、一様最強力検定
(1)と同様に
$R = \left\{ \bm{x} \in \mathcal{X} \;\middle|\; 2\lambda_0 \sum x_i \ge \chi^2_{2n, \alpha} \right\}$
が与えられる。(?)
