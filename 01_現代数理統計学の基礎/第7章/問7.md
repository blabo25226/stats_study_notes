# 第7章 問7

## 問題の要約

$X_1, \dots, X_n \stackrel{\mathrm{i.i.d.}}{\sim} Ex(\theta)$、$Y_1, \dots, Y_m \stackrel{\mathrm{i.i.d.}}{\sim} Ex(\mu)$ とし、2つの標本は互いに独立とする。

(1) $\sum_{i=1}^n X_i, \sum_{j=1}^m Y_j$ の分布を求める。
(2) $H_0: \theta = \mu$ vs $H_1: \theta \neq \mu$ なる仮説検定問題に対して尤度比検定を与え、この検定統計量が $Z = \sum_{i=1}^n X_i / (\sum_{i=1}^n X_i + \sum_{j=1}^m Y_j)$ なる統計量に基づいていることを示す。
(3) 帰無仮説 $H_0$ が正しいときの $Z$ の分布を求め、$Z$ を用いた有意水準 $\alpha$ の検定を与える。

## 答案

$X_1, \dots, X_n \stackrel{\mathrm{i.i.d.}}{\sim} Ex(\theta), Y_1, \dots, Y_m \sim Ex(\mu)$
$X, Y$ は独立。

(1)
$\sum X_i, \sum Y_j$ の分布を求める。
$M_{\sum X_i}(t) = E\left[e^{t\sum X_i}\right] = \prod_{i=1}^n E\left[e^{tX_i}\right]$
$E\left[e^{tX_i}\right] = \int_0^\infty e^{tx} \theta e^{-\theta x} dx = \int_0^\infty \theta e^{-(t-\theta)x} dx = \left[ -\frac{\theta}{\theta - t} e^{-(\theta - t)x} \right]_0^\infty \quad (t - \theta < 0 \text{ とする})$
$= \frac{\theta}{t - \theta}(0 - 1) = \frac{\theta}{\theta - t} \quad (t < \theta \text{ より})$
$M_{\sum X_i}(t) = \left(\frac{\theta}{\theta - t}\right)^n = \left(\frac{1}{1 - \frac{t}{\theta}}\right)^n$ より $\sum X_i \sim Ga\left(n, \frac{1}{\theta}\right)$
同様にして $\sum Y_j \sim Ga\left(m, \frac{1}{\mu}\right)$

(2)
$L(\theta, \mu \mid \bm{x}, \bm{y}) = \prod_{i=1}^n \theta e^{-\theta x_i} \prod_{j=1}^m \mu e^{-\mu y_j} = \theta^n e^{-\theta \sum x_i} \mu^m e^{-\mu \sum y_j} = \theta^n \mu^m \exp(-n\theta\bar{x} - m\mu\bar{y})$
$H_0: \theta = \mu$ のもと最尤推定を行う。
$L(\theta \mid \bm{x}, \bm{y}) = \theta^{n+m} \exp(-\theta(n\bar{x} + m\bar{y}))$
$l(\theta) = (n+m)\log\theta - \theta(n\bar{x} + m\bar{y})$
$\frac{\partial l}{\partial \theta} = \frac{n+m}{\theta} - (n\bar{x} + m\bar{y}) = 0 \implies \hat{\theta}_0 = (n+m)\left(\sum x_i + \sum y_j\right)^{-1}$

$H_1: \theta \neq \mu$ のもとでは
$l(\theta, \mu) = n\log\theta + m\log\mu - n\theta\bar{x} - m\mu\bar{y}$
$\frac{\partial l}{\partial \theta} = \frac{n}{\theta} - n\bar{x} \implies \hat{\theta} = \frac{1}{\bar{x}}$
$\frac{\partial l}{\partial \mu} = \frac{m}{\mu} - m\bar{y} \implies \hat{\mu} = \frac{1}{\bar{y}}$

よって
$\Lambda(\bm{x}, \bm{y}) = \frac{L(\hat{\theta}_0 \mid \bm{x}, \bm{y})}{L(\hat{\theta}, \hat{\mu} \mid \bm{x}, \bm{y})} = \frac{\hat{\theta}_0^{n+m} \exp(-\hat{\theta}_0(\sum x_i + \sum y_j))}{\hat{\theta}^n \hat{\mu}^m \exp(-n\hat{\theta}\bar{x} - m\hat{\mu}\bar{y})}$
$= \frac{\hat{\theta}_0^{n+m} \exp(-\hat{\theta}_0 \cdot (n+m)\hat{\theta}_0^{-1})}{\hat{\theta}^n \hat{\mu}^m \exp(-n - m)} = \frac{\hat{\theta}_0^{n+m}}{\hat{\theta}^n \hat{\mu}^m} \exp(-(n+m) + (n+m)) = \frac{\hat{\theta}_0^{n+m}}{\hat{\theta}^n \hat{\mu}^m}$
$= \frac{(n+m)^{n+m} (\sum x_i + \sum y_j)^{-(n+m)}}{\left(\frac{1}{\bar{x}}\right)^n \left(\frac{1}{\bar{y}}\right)^m} = \frac{(n+m)^{n+m}(\sum x_i)^n (\sum y_j)^m}{n^n m^m (\sum x_i + \sum y_j)^{n+m}}$

より検定は $R = \left\{ \bm{x} \in \mathcal{X}, \bm{y} \in \mathcal{Y} \;\middle|\; \frac{(\sum x_i)^n (\sum y_j)^m}{(\sum x_i + \sum y_j)^{n+m}} > c \right\}$
また $Z = \frac{\sum x_i}{\sum x_i + \sum y_j}$ について
$\sum x_i + \sum y_j = \frac{\sum x_i}{Z}, \quad \sum x_i + \sum y_j = \frac{\sum y_j}{1 - Z}$ より
$\Lambda(\bm{x}, \bm{y}) = \frac{(n+m)^{n+m}}{n^n m^m} \cdot \frac{(\sum x_i)^n}{\frac{(\sum x_i)^n}{Z^n}} \cdot \frac{(\sum y_j)^m}{\frac{(\sum y_j)^m}{(1-Z)^m}} = \frac{(n+m)^{n+m}}{n^n m^m} \cdot Z^n (1-Z)^m$
よりこの検定は $Z$ に基づいていると言える。
