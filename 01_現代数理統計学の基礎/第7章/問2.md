# 第7章 問2

## 問題の要約

$X_1, \dots, X_n \stackrel{\mathrm{i.i.d.}}{\sim} N(\mu, \sigma^2)$ とし、$\mu_0, \sigma_0^2$ を既知とする。以下の検定問題について有意水準 $\alpha$ の尤度比検定を与える。

(1) $\sigma^2$ が既知のとき、$H_0: \mu \le \mu_0$ vs $H_1: \mu > \mu_0$
(2) $\mu$ が既知のとき、$H_0: \sigma^2 \le \sigma_0^2$ vs $H_1: \sigma^2 > \sigma_0^2$

## 答案

(1)
$L(\mu, \sigma^2 \mid \bm{x}) = (2\pi\sigma^2)^{-\frac{n}{2}} \exp\left(-\frac{\sum (x_i - \bar{x})^2}{2\sigma^2} - \frac{n(\bar{x} - \mu)^2}{2\sigma^2}\right)$
$\sigma^2$ は既知とする。
$\mu$ の最尤推定量は $\hat{\mu} = \bar{x}$ である。
$H_0: \mu \le \mu_0$ のもとでの $\mu$ の最尤推定量は $\hat{\mu}_0 = \min(\bar{x}, \mu_0)$ となる。
尤度比は
$\Lambda(\bm{x}) = \frac{L(\hat{\mu}_0, \sigma^2 \mid \bm{x})}{L(\hat{\mu}, \sigma^2 \mid \bm{x})} = \exp\left(-\frac{n(\bar{x} - \hat{\mu}_0)^2}{2\sigma^2}\right)$
- $\bar{x} \le \mu_0$ のとき $\hat{\mu}_0 = \bar{x}$ より $\Lambda(\bm{x}) = 1$
- $\bar{x} > \mu_0$ のとき $\hat{\mu}_0 = \mu_0$ より $\Lambda(\bm{x}) = \exp\left(-\frac{n(\bar{x} - \mu_0)^2}{2\sigma^2}\right)$

したがって
$-2\log\Lambda(\bm{x}) = \begin{cases} 0 & (\bar{x} \le \mu_0) \\ \frac{n(\bar{x} - \mu_0)^2}{\sigma^2} & (\bar{x} > \mu_0) \end{cases}$

$\bar{x} > \mu_0$ のとき、棄却域は
$\frac{\sqrt{n}(\bar{x} - \mu_0)}{\sigma} > c$
と同値になる。
$H_0: \mu = \mu_0$ のもとで $\frac{\sqrt{n}(\bar{X} - \mu_0)}{\sigma} \sim N(0, 1)$ であるから、有意水準 $\alpha$ の棄却域は
$R = \left\{ \bm{x} \in \mathcal{X} \;\middle|\; \frac{\sqrt{n}(\bar{x} - \mu_0)}{\sigma} > z_\alpha \right\}$
サイズ条件の確認：
$\mu \le \mu_0$ に対して
$P_\mu\left(\frac{\sqrt{n}(\bar{X} - \mu_0)}{\sigma} > z_\alpha\right) = P\left(Z > z_\alpha + \frac{\sqrt{n}(\mu_0 - \mu)}{\sigma}\right) \le P(Z > z_\alpha) = \alpha$
となり、$\sup_{\mu \le \mu_0} P_\mu(\bm{X} \in R) = \alpha$ が成り立つ。

---

(2)
$\mu$ は既知とする。
$\hat{\sigma}_0^2 = \frac{1}{n} \sum_{i=1}^n (x_i - \mu)^2$ とおく。
制約のない最尤推定量は $\hat{\sigma}^2 = \hat{\sigma}_0^2$。
$H_0: \sigma^2 \le \sigma_0^2$ のもとでの最尤推定量は $\hat{\sigma}_{H_0}^2 = \min(\hat{\sigma}_0^2, \sigma_0^2)$ となる。
尤度比は
$\Lambda(\bm{x}) = \frac{L(\mu, \hat{\sigma}_{H_0}^2 \mid \bm{x})}{L(\mu, \hat{\sigma}^2 \mid \bm{x})} = \left(\frac{\hat{\sigma}^2}{\hat{\sigma}_{H_0}^2}\right)^{\frac{n}{2}} \exp\left(-\frac{n\hat{\sigma}^2}{2\hat{\sigma}_{H_0}^2} + \frac{n}{2}\right)$
- $\hat{\sigma}_0^2 \le \sigma_0^2$ のとき $\hat{\sigma}_{H_0}^2 = \hat{\sigma}_0^2$ より $\Lambda(\bm{x}) = 1$
- $\hat{\sigma}_0^2 > \sigma_0^2$ のとき $\hat{\sigma}_{H_0}^2 = \sigma_0^2$ より
$\Lambda(\bm{x}) = \left(\frac{\hat{\sigma}_0^2}{\sigma_0^2}\right)^{-\frac{n}{2}} \exp\left(-\frac{n\hat{\sigma}_0^2}{2\sigma_0^2} + \frac{n}{2}\right)$

$-2\log\Lambda(\bm{x}) = \begin{cases} 0 & (\hat{\sigma}_0^2 \le \sigma_0^2) \\ n\left(\frac{\hat{\sigma}_0^2}{\sigma_0^2} - \log\frac{\hat{\sigma}_0^2}{\sigma_0^2} - 1\right) & (\hat{\sigma}_0^2 > \sigma_0^2) \end{cases}$

$\hat{\sigma}_0^2 > \sigma_0^2$ のとき、$-2\log\Lambda(\bm{x})$ は $\frac{\hat{\sigma}_0^2}{\sigma_0^2}$ の単調増加関数であるため、
棄却域は $\frac{n\hat{\sigma}_0^2}{\sigma_0^2} > c$ の形になる。
漸近的に $-2\log\Lambda(\bm{x}) \xrightarrow{d} \chi^2_1$ より
$R = \left\{ \bm{x} \in \mathcal{X} \;\middle|\; n\left(\frac{\hat{\sigma}_0^2}{\sigma_0^2} - \log\frac{\hat{\sigma}_0^2}{\sigma_0^2} - 1\right) > \chi^2_{1, \alpha} \right\}$
（※あるいは $\frac{n\hat{\sigma}_0^2}{\sigma_0^2} \sim \chi^2_n$ より $\frac{n\hat{\sigma}_0^2}{\sigma_0^2} > \chi^2_{n, \alpha}$）
