# 第4章 問22

## 問題の要約

確率変数 $(X, Y)$ の同時確率密度関数が
$$
f(x, y) = C_{a,b,c} \, x^{a-1} y^{b-1} (1 - x - y)^{c-1} \quad (x > 0, y > 0, x + y < 1)
$$
で与えられる（ディリクレ分布 $\mathrm{Dir}(a, b, c)$）。ここで $a, b, c > 0$ である。
1. 正規化定数 $C_{a,b,c}$ をガンマ関数を用いて表せ。
2. $X$ および $Y$ の周辺確率密度関数を求めよ。
3. $X = x$ が与えられたときの $Y$ の条件付き確率密度関数 $f_{Y \mid X}(y \mid x)$ を求めよ。
4. $E[X], V(X), \mathrm{Cov}(X, Y)$ および相関係数 $\mathrm{Corr}(X, Y)$ を求めよ。
