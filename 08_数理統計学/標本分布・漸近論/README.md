## 必須の区別

- **有限標本で厳密**：正規標本の$\bar X$、残差平方和のカイ二乗、t・F統計量（モデルの仮定が必要）。
- **分布収束**：一般のiid標本平均のCLT、標準化MLEの正規極限、順序統計量の非退化な極限。
- **確率収束・概収束**：大数の法則と標本分散の一致性。$\xrightarrow P$と$\xrightarrow{\mathrm{a.s.}}$を混同しない。
- **独立性の根拠**：同時正規＋共分散ゼロなら独立だが、一般の確率変数では無相関だけで独立といえない。
- **定理を使う際の仮定**：非退化な分散、iid、母数空間の内部点、識別可能性、十分な滑らかさなどを明記。
- **2次デルタ法**：$g'(\theta)=0$なら$N(0,\cdot)$の1次近似は退化し、$n$倍の変換でカイ二乗型の極限が出る。

## どこまで証明したか

各ノートでは、使用する標本の仮定から具体的な分布・確率収束が出るまでを数式で導出した。ただし**Lévyの連続性定理、Portmanteauの定理、Kolmogorovの収束判定、Kroneckerの補題、Borel–Cantelliの補題そのものの一般証明**は、このフォルダでは外部の基礎定理として利用している。これらの定理の根本からの証明まで完備したとは主張しない。

統計検定1級の答案では、証明の前に必要な仮定と「有限標本で厳密か、極限の結果か」を示すこと。各ノートには計算・分布導出の例題（過去問改題、出典付き）と折りたたみ式解答がある。
