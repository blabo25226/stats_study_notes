# 一般化線形回帰 — 推定と検定の証明索引

| ノート | 主な導出 |
|---|---|
| [[一般化線形モデル]] | 指数型分布族から$E[Y]$・$\operatorname{Var}(Y)$、一般スコア・Fisher情報、IRLS、逸脱度 |
| [[ロジスティック回帰]] | Bernoulli/binomialの対数尤度、スコア、負Hessian、IRLS、Wald・尤度比検定 |
| [[ポアソン回帰]] | 対数リンク・オフセット、スコア・情報行列、ポアソン逸脱度、等発生率のexact条件付き二項検定 |

## 区別

- **正規線形回帰の$t/F$**：仮定が揃えば有限標本で厳密。誤差正規性・独立性・等分散性・設計ランクを点検する。
- **ロジスティック／ポアソン回帰のWald・尤度比・Score**：通常は大標本の**漸近正規・漸近カイ二乗**。希少事象、分離、0セル、境界では近似に注意。
- **ポアソンの2群等発生率検定**：合計イベント数で条件付ければ**exactな二項分布**に還元できる場合がある。
- **残差逸脱度**：モデルのあてはまりの指標であり、一般に有限標本で$\chi^2$に厳密に従うわけではない。
- **標準誤差**：Fisher情報の逆行列はモデルの平均・分散関係が正しい場合の推定。過分散・クラスタリング・不均一分散は別途考慮する。
