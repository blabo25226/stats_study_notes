# 推定・検定・漸近論：統計検定1級の導出マップ

2026年10月改訂。対象は次の3フォルダの計39件の既存概念ノート。

- 推定論：不偏性・MSE・最尤法・情報量・十分性・信頼区間（15件）
- [[仮説検定]]：t・カイ二乗・Wald・Score・尤度比・多重比較・同等性など（17件）
- [[中心極限定理]]：標本平均・大数の法則・順序統計量・デルタ法・漸近分布（7件）

今回の学習の中心は「**どの統計量が、どの仮定で、どの分布に従うか**」を説明すること。試験で表・四則演算・平方根から再現できる式を中心に、各ノートにオリジナル演習を追加した。

## 優先度A：分布の生成と検定統計量の導出

1. [[標本平均]]・[[正規標本から導くt・カイ二乗・F統計量]]：正規ベクトルの直交射影から残差平方和の自由度を証明する。
2. [[t検定]]・[[カイ2乗検定]]：標本平均と独立なカイ二乗分布を組み合わせる。カテゴリ度数の制約と漸近自由度を説明する。
3. [[フィッシャー情報量]] → [[クラメール・ラオの不等式]] → [[最尤推定量]]：スコアから情報量、分散下界を導く。
4. [[尤度比検定]]・[[スコア検定]]・[[ワルド検定]]：帰無パラメータで計算するか、MLEが必要か、なぜ大標本で $\chi^2_1$ となるかを比較する。
5. [[中心極限定理]] → [[漸近分布]] → [[デルタ法]]：変換後の推定量の漸近分散を計算する。

## よく混同する式の一覧

| 統計量 | 条件 | 帰無・標本分布 |
|---|---|---|
| $\sqrt n(\bar X-\mu)/\sigma$ | 独立な正規標本、$\sigma$ 既知 | $N(0,1)$（厳密） |
| $\sum_i(X_i-\bar X)^2/\sigma^2$ | 独立な正規標本 | $\chi^2_{n-1}$（厳密） |
| $\sqrt n(\bar X-\mu)/S$ | 独立な正規標本、$S^2$ は不偏分散 | $t_{n-1}$（厳密） |
| $S_1^2/S_2^2$ | 独立な2正規群・等母分散 | $F(n_1-1,n_2-1)$（厳密） |
| 群間平均平方 / 群内平均平方 | 独立な等分散正規群、共通平均の帰無仮説 | $F(k-1,N-k)$（厳密） |
| スコア・Wald・尤度比 | 正則な大標本、内部点での帰無仮説など | $\chi^2_r$（**漸近**） |
| Pearson度数統計量 | 適切な帰無度数・十分な標本 | $\chi^2_{\mathrm{df}}$（**漸近**） |

**厳密分布と漸近分布、自由度と母数の存在条件、独立性の条件を混同しないこと。**

## 演習の進め方

1. 分布や尤度を先に書き、台・正規性・独立性・分散の既知性を明示する。
2. 推定量の期待値、分散、スコア・情報量の導出を行う。
3. 臨界値は該当分布の上側付表から読む。表がなければ記号で答える。
4. 解答コールアウトを開いて数式・自由度・境界条件を確認する。

**第1回**の確率分布19件はPR #4でmain統合済み。**第3回**はPR #6でmain統合済みで、回帰・分散分析・生存解析・多次元・ベイズ・ノンパラメトリックなどを扱う。今回の独自演習は元の過去問の転載ではない。
