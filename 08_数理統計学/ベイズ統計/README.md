## 共役更新を確認する順序

1. **尤度**を書く。事前と積を取り、母数について定数の因子を除く。
2. **正規化できること**を確かめる（ベータ／ガンマ積分、平方完成など）。
3. 事後母数を求める。ガンマの**尺度と率**、逆ガンマのパラメータ化に注意する。
4. **推定する目的**を区別する：母数の事後平均・中央値・MAP、母数の信用区間、新観測の事後予測。
5. 事後予測では**母数を積分する**。事後平均を単に代入したプラグイン予測とは一般に一致せず、予測分散には母数不確実性も含まれる。

正規–逆ガンマでの$t$のパラメータ$s$は**尺度**であり、$\operatorname{Var}(T)=\nu s^2/(\nu-2)$（$\nu>2$）。ガンマ–ポアソン予測は負の二項分布となる。
