# 08_数理統計学 第3回 — 応用分野と確率の基本

本マップは、統計検定1級「統計数理」と「統計応用（医薬生物学）」の演習をつなぐ学習案内。第3回の改訂対象は **38件の概念ノート**（確率・期待値9件、多次元確率変数8件、一般化線形回帰3件、分散分析6件、ベイズ統計2件、ノンパラメトリック統計5件、生存解析5件）。各ノートにオリジナル例題と導出を追加した。

## 優先度A — 医薬生物学の得点源

1. **2×2表と診断検査**：[[統計指標]] → [[ベイズの定理]] → [[リスク比とオッズ比]] → [[ロジスティック回帰]]。疾患確率・感度・特異度の条件の向き、RRとORの違いに注意。
2. **生存解析**：[[ハザード関数]] → [[打ち切りと尤度]] → [[カプラン・マイヤー推定量]] → [[Cox比例ハザードモデル]] → [[競合リスク]]。打ち切りを死亡と数えない。CIFと $1-\mathrm{KM}$ を混同しない。
3. **分散分析**：[[コクランの定理]] → [[一元配置分散分析]] → [[二元配置分散分析]] → [[線形対比とDunnett検定]] → [[閉手順]]。平方和・自由度・残差平均平方からt・F統計量を導出する。
4. **共変量調整**：[[単・重回帰]] → [[共分散分析]] → [[交絡とシンプソンのパラドックス]]。無作為化・調整・交絡・非併合性を区別する。

## 優先度B — 統計数理と応用をつなぐ

- **二変量の確率計算**：[[独立性]] → [[条件付き分布]] → [[条件付き期待値]] → [[条件付き分散]]。反復期待値と全分散の法則を使い、混合分布の平均・分散を求める。
- **正規の条件付け**：[[共分散]] → [[相関係数]] → [[2変量正規分布]]。条件付き平均と残差分散 $\sigma_2^2(1-\rho^2)$ を導出する。
- **ポアソン回帰**：[[ポアソン回帰]]。率 $\lambda$ と観察人時 $t$ の関係 $\mu=t\lambda$、オフセット $\log t$ を理解する。
- **ベイズ予測**：[[ベイズ推定の基本]]。ベータ–二項モデルで次の2例の事後予測を $E[p^2\mid x]$ として計算する。

## 優先度C — 正確検定と分布の計算

- [[符号検定]]：$T\sim\operatorname{Bin}(n,1/2)$ の正確な尾確率。
- [[ウィルコクソン符号付き順位検定]]：$W^+=\sum_jjB_j$ の正確分布。
- [[ウィルコクソン順位和検定]]：順位和とMann–WhitneyのUの関係。
- [[並び替え検定]]：全割り付けの数え上げと交換可能性。
- [[モーメント]]、[[期待値]]、[[分散]]、[[分布関数]]、[[確率密度関数]]、[[変数変換]]、[[積率母関数]]：定義から積分・和で計算する。
- [[変動係数]]、[[歪度_尖度]]：分布の形状と尺度に依存しない指標を確認する。

## 実戦答案のチェック項目

1. $P(Y\mid X)$ と $P(X\mid Y)$ の取り違えはないか。
2. 独立・正規・等分散・非情報的打ち切り・比例ハザードなど**モデルの仮定**を宣言したか。
3. カイ二乗・t・Fの**自由度と厳密分布／漸近分布**を区別したか。
4. RR（確率の比）、OR（オッズの比）、HR（瞬間ハザードの比）を混同していないか。
5. 条件付きと周辺、率と尺度、事後平均と事後予測を取り違えていないか。
6. 分散は非負か、確率は $[0,1]$ か、積分した密度は1になるか。
