# ノンパラメトリック検定 — exact と正規近似

このフォルダの4つの検定ノートでは、**正確（exact）検定と正規近似**をそれぞれ導出し、別々のオリジナル例題を解く。検定を実施する前に「帰無仮説」「交換可能性や対称性」「同順位・ゼロ差」「片側・両側」を確認する。

| 検定 | exact の帰無分布 | 正規近似の中心・分散（基本形） | 例題 |
|---|---|---|---|
| [[符号検定]] | $\operatorname{Bin}(n,1/2)$ | $E[T]=n/2,\ \operatorname{Var}(T)=n/4$ | 小標本6人／大標本100人 |
| [[ウィルコクソン符号付き順位検定]] | 全 $2^n$ 通りの符号付けによる順位和分布 | $E[W^+]=n(n+1)/4,\ \operatorname{Var}(W^+)=n(n+1)(2n+1)/24$ | $n=4$／$n=20$ |
| [[ウィルコクソン順位和検定]] | 全 $\binom{m+n}{m}$ 通りの順位割付分布 | $E[U]=mn/2,\ \operatorname{Var}(U)=mn(m+n+1)/12$ | $m=2,n=3$／$m=n=20$ |
| [[並び替え検定]] | 全割付の統計量を数え上げ | **統計量による**。二値データの処置群成功数は超幾何分布を正規近似できる | $2$ 対 $2$ の全割付／$20$ 対 $20$ の二値比較 |

## どちらを使うか

- **exact**：小標本で適する。正確な帰無分布が求まれば、大標本でもexactを用いてよい。正規性は不要だが、**各検定が必要とする帰無仮説・交換可能性・対称性**は別に必要。
- **正規近似**：両群の標本サイズが増え、近似を正当化できる中心極限定理と分散条件があるとき。有限標本では近似誤差があり、尾確率で差が出やすい。
- **連続性補正**：整数の統計量について $P(T\ge t)$ は通常 $P(Z\ge(t-0.5-\mu)/\sigma)$ と近似する。下側では $+0.5$ の向き。順位に同順位がある場合、値の刻み幅が変わることにも注意。
- **同順位・0差**：符号検定は0差を除いて有効標本数を更新。符号付き順位検定も0差を除き、同順位には平均順位・適切な分散を用いる。順位和検定では同順位補正を用いる。
- **両側P値**：対称なexact帰無分布（上記3つの基本形）なら両側尾確率を対応させられる。ただし、**一般の並び替え検定では、どの統計量を「より極端」とみなすかを先に定める**必要があり、単純に片側P値を2倍してはいけない。
- **モンテカルロ並び替え**：割付全列挙の代わりに無作為な割付を標本抽出する方法。**正規近似とは別の近似**であり、有限 $B$ によるシミュレーション誤差を持つ。

## 学習の順序

最初に[[符号検定]]で二項分布のexactと正規近似を比べ、次に[[ウィルコクソン符号付き順位検定]]で「順位の重み」と符号の対称性を学ぶ。その後[[ウィルコクソン順位和検定]]で対比較統計量 $U$ と平均・分散を導き、最後に[[並び替え検定]]で**任意の統計量に普遍的な正規近似はない**ことを確認する。

> [!note] 試験で書くべきこと
> 「統計量」「帰無仮説下の分布（正確か漸近か）」「自由度や期待値・分散」「P値の尾の向き」「連続性補正の有無」「必要な仮定」を順に示す。片側と両側を混同しない。
