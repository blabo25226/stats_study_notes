# 多変量解析 — 固有値問題と判別の索引

統計応用の共通事項（主成分分析・因子分析・判別分析・クラスター分析）を扱う。いずれも共分散行列（または相関行列）の固有値問題か、[[多変量正規分布]]の尤度比に帰着させて計算する。

| ノート | 導出の中心 | 例題 |
|---|---|---|
| [[主成分分析]] | 分散最大化→ラグランジュ乗数→固有値問題、寄与率、2変量で固有値 $1\pm\rho$ | 2×2共分散行列の固有値・固有ベクトル、共分散と相関行列の違い |
| [[判別分析]] | 等共分散正規の対数尤度比が線形、マハラノビス距離、誤判別確率 $\Phi(-\Delta/2)$、フィッシャーの基準 | 2群2変量の線形判別と事前確率による閾値の移動 |
| [[因子分析とクラスター分析]] | $\Sigma=\Lambda\Lambda^\top+\Psi$、共通性・独自性、連結法とウォード法、k-meansの単調減少 | 1因子モデルの負荷量、5点の樹形図とk-means |

## 学ぶ順序

1. [[多変量正規分布]]・[[条件付き正規分布]]で共分散行列の扱いを確認する。
2. [[主成分分析]]で固有値問題として最大化を解く。
3. [[判別分析]]で尤度比とマハラノビス距離から誤判別確率を計算する。
4. [[因子分析とクラスター分析]]で主成分分析との違いと、距離による分類を確認する。
