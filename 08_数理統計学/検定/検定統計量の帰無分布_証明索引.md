# 検定統計量の帰無分布 — 証明索引

「何分布に従うか」は、**帰無仮説・独立性・標本抽出・母数空間・有限標本か極限か**を指定して初めて答えられる。分布の証明が必要な検定と、検定法の水準・検出力を証明する手法を区別する。

## 1. 正規モデルとF検定

| 検定 | 帰無分布 | 証明の中心 |
|---|---|---|
| 1標本・対応のある[[t検定]] | 正規差の下で厳密に$t_{n-1}$ | 平均・残差平方和の直交独立性 |
| 等分散2標本[[t検定]] | 正規・等分散で厳密に$t_{n_1+n_2-2}$ | 2群残差平方和の独立なカイ二乗和 |
| Welchの[[t検定]] | 通常はSatterthwaiteの**近似**t | 独立標本分散のモーメント一致 |
| 正規2標本の分散比 | 等分散帰無で厳密に$F(n_1-1,n_2-1)$ | [[正規標本から導くt・カイ二乗・F統計量]]の分散比 |
| [[一元配置分散分析]] | 正規・等分散・帰無で厳密に$F(k-1,N-k)$ | [[コクランの定理]]と直交射影 |
| [[二元配置分散分析]]の交互作用 | 平衡正規モデルで厳密に$F((a-1)(b-1),ab(r-1))$ | 平衡配置の直交射影 |
| [[共分散分析]]の群効果 | 正規線形モデルで厳密に$F(q,N-p)$ | 帰無・無制約モデルの残差平方和差 |
| [[線形対比とDunnett検定]] | 単独対比は$t_{N-k}$、Dunnettは**相関する多変量t** | 正規群平均と共有対照の共分散 |

## 2. 尤度・スコア・カウントの検定

| 検定 | 帰無分布 | 証明の中心 |
|---|---|---|
| [[ワルド検定]] | 正則な内部点で漸近$\chi_r^2$ | MLEの漸近正規性＋連続写像 |
| [[スコア検定]] | 正則な内部点で漸近$\chi_r^2$ | スコアの中心極限定理 |
| [[尤度比検定]] | 正則な内部点で漸近$\chi_r^2$ | Taylor展開とWilks型定理 |
| [[適合度検定]] | 既知の$k$カテゴリで漸近$\chi_{k-1}^2$ | 多項CLT＋階数$k-1$の射影 |
| [[カイ2乗検定]]（独立性・一様性） | 漸近$\chi_{(r-1)(c-1)}^2$ | 飽和・独立モデルの自由度差 |
| [[2×2分割表]]のFisher正確検定 | 周辺固定で**厳密な超幾何分布** | 全割付の組合せを条件付けて数える |
| [[リスク比とオッズ比]]のWald検定 | 大標本で漸近$N(0,1)$、二乗が$\chi_1^2$ | 2群の二項CLT＋デルタ法 |
| [[オッズ比の均一性検定]]（Woolf型） | $K$層で漸近$\chi_{K-1}^2$ | 対数ORのCLTと射影二次形式 |
| [[マクネマー検定]] | 不一致ペア数で条件付けると厳密に二項$(n_{10}+n_{01},1/2)$、統計量は漸近$\chi_1^2$ | 多項分布の制約付きMLEとスコア |
| [[マンテル・ヘンツェル法とコクラン検定]] | 層数固定・各層大標本で漸近$\chi_1^2$（CMHは超幾何分散、Cochranは積二項分散） | 層ごとの$O-E$の和のCLT |
| [[コクラン・アーミテージ傾向性検定]] | 大標本で漸近$N(0,1)$、二乗が$\chi_1^2$ | 二項CLTと用量スコアへの射影 |
| [[ログランク検定]] | 十分なイベント数等の下で漸近$N(0,1)$、二乗が$\chi_1^2$ | 条件付き超幾何分散＋マルチンゲールCLT |
| [[Cox比例ハザードモデル]]のスコア検定 | 正則条件下で漸近$\chi_1^2$ | 部分尤度のスコア＋マルチンゲールCLT |

## 3. ノンパラメトリック・無作為化

| 検定 | exact帰無分布 | 正規近似の根拠 |
|---|---|---|
| [[符号検定]] | 独立な符号の二項$(n,1/2)$ | iidベルヌーイのCLT |
| [[ウィルコクソン符号付き順位検定]] | 独立な符号の$2^n$個の部分集合和 | 最大重みが無視できるLindeberg–Feller CLT |
| [[ウィルコクソン順位和検定]]・[[マン・ホイットニー検定]] | $\binom{m+n}{m}$個の順位割付 | 2標本U統計量のHájek射影＋CLT |
| [[並び替え検定]] | 交換可能な全割付でexact P値 | **統計量次第**。二値成功数なら有限母集団CLT |
| [[置換検定とランダム化検定]] | 全割付のexact、モンテカルロの水準保証 | モンテカルロ近似は正規近似と別物 |
| [[コルモゴロフ・スミルノフ検定]] | 連続な帰無分布で $F_0$ によらない（分布不変） | 確率積分変換で一様分布に帰着 |

## 解答時のチェック項目

1. 帰無分布は**有限標本でexact**か、$n\to\infty$の**漸近分布**か。
2. 独立性、正規性、等分散、対称性、交換可能性、非情報的打ち切りを確認したか。
3. 分母の分散推定量は独立か。自由度は射影の階数や推定母数数から求めたか。
4. 両側検定か片側検定か。連続性補正と同順位の扱いを明記したか。
5. 境界・0セル・少数イベント・非識別性など、極限定理が適用できない状況を見逃していないか。
6. 「分布の証明」「P値の水準制御」「検出力・最強性」のどれが問われているかを明確にしたか。

ノートは理論別に配置しているため、同じ検定（Mann–WhitneyとWilcoxon順位和など）が複数ファイルから参照される場合がある。実際の証明は上記のリンク先に追記している。
