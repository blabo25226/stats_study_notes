# 確率分布 — 統計検定1級のための導出マップ

このフォルダの19種類の分布について、**定義 → モーメント導出 → 分布間の関係 → 十分統計量・最尤推定量 → オリジナル演習**の順に学習する。

> [!important] パラメータ化
> 本Vaultの [[ガンマ分布]] は形状・**尺度**、[[指数分布]] は**率**、[[幾何分布]] と [[負の二項分布]] は成功前の**失敗回数**で定義している。記号だけで意味を推測しない。

なお[[多項分布]]はベクトル値の分布として **`08_数理統計学/多次元確率変数/多項分布.md`** へ移動した。多項分布の期待値・共分散・十分統計量・ラグランジュ未定乗数法による最尤推定は、移動先のノートで扱う。

## 十分統計量・最尤推定量：19分布の索引

各ノートで $X_1,\ldots,X_n$ を独立同分布の標本とし、同時尤度から**因子分解定理による十分性**と**尤度の最大化**を導出した。順序統計量は $X_{(1)}=\min_iX_i$、$X_{(n)}=\max_iX_i$ と表記する。

| 分布 | 主な未知母数 | 十分統計量 | MLEの導出方法 |
|---|---|---|---|
| [[ベルヌーイ分布]] | $p$ | $\sum X_i$ | スコアと端点 |
| [[二項分布]] | $p$（試行回数は既知） | $\sum X_i$ | スコア |
| [[ポアソン分布]] | $\lambda$ | $\sum X_i$ | スコア・0の境界 |
| [[幾何分布]] | $p$ | $\sum X_i$ | スコア・1の境界 |
| [[負の二項分布]] | $p$／$(r,p)$ | $r$既知なら$\sum X_i$、両未知なら頻度表 | スコア・プロファイル |
| [[超幾何分布]] | $M$（$N,K$既知） | 観測度数のヒストグラム | 整数候補の直接比較 |
| [[一様分布]] | $a,b$ | $X_{(1)},X_{(n)}$ | 区間幅の最小化 |
| [[パレート分布]] | $x_m,a$ | $X_{(1)},\sum\log X_i$ | 端点→形状スコア |
| [[指数分布]] | 率$\lambda$ | $\sum X_i$ | スコア |
| [[ガンマ分布]] | 形状$\alpha$・尺度$\beta$ | $\sum X_i,\sum\log X_i$ | プロファイル・数値解 |
| [[ベータ分布]] | 形状$a,b$ | $\sum\log X_i,\sum\log(1-X_i)$ | 連立スコア・数値解 |
| [[正規分布]] | $\mu,\sigma^2$ | $\sum X_i,\sum X_i^2$ | 連立スコア |
| [[対数正規分布]] | $\mu,\sigma^2$ | $\sum\log X_i,\sum(\log X_i)^2$ | 対数変換後のスコア |
| [[ラプラス分布]] | $\mu,\sigma$ | 全順序統計量 | 絶対偏差・中央値 |
| [[ワイブル分布]] | $k,\eta$ | 全順序統計量（$k$既知なら$\sum X_i^k$） | プロファイル・数値解 |
| [[コーシー分布]] | $\mu,\gamma$ | 全順序統計量 | 非凹尤度の大域最大 |
| [[カイ二乗分布]] | $\nu$（通常は既知） | $\sum\log X_i$ | ディガンマ方程式 |
| [[t分布]] | $\nu$（通常は既知） | $\operatorname{sort}(X_1^2,\ldots,X_n^2)$ | 数値解・境界の比較 |
| [[F分布]] | $u,v$（通常は既知） | 全順序統計量 | 連立スコア・境界比較 |

**注意事項**：試行回数や自由度が既知なら推定対象ではない。一様・Paretoなどの母数依存の台ではスコア=0が使えないことがある。MLEの存在・一意性は分布と標本によって異なる。多項分布の確率和制約にはラグランジュ未定乗数法を使う。

## 必須の分布間の関係

$$
\operatorname{Bin}(n,\lambda/n)\ \Rightarrow\ \operatorname{Po}(\lambda)
\quad(n\to\infty,\ \lambda>0).
$$

$$
\frac{\operatorname{Po}(\lambda)-\lambda}{\sqrt\lambda}\ \Rightarrow\ N(0,1)
\quad(\lambda\to\infty).
$$

$$
Z_i\stackrel{\mathrm{iid}}{\sim}N(0,1)
\ \Longrightarrow\ \sum_{i=1}^\nu Z_i^2\sim\chi_\nu^2.
$$

$$
Z\sim N(0,1),\ V\sim\chi_\nu^2,\ Z\perp V
\ \Longrightarrow\ \frac{Z}{\sqrt{V/\nu}}\sim t_\nu.
$$

$$
U\sim\chi_m^2,\ V\sim\chi_n^2,\ U\perp V
\ \Longrightarrow\ \frac{U/m}{V/n}\sim F(m,n).
$$

$Z,U,V$ の**独立性**を欠く場合、最後の2つの分布関係は一般に成立しない。

### 「密度と確率質量関数」の読み方

- **離散→離散**：$P(X_n=k)\to P(X=k)$（各固定$k$）を示す。
- **離散→連続**：$P(Z_n=x)$が連続密度へ直接収束するという意味ではない。適切に標準化し、各格子の**質量÷格子幅**（局所CLT）で密度を近似する。分布収束自体は分布関数・MGF・CLT等で示す。
- **連続→連続**：適切に標準化した変数の密度の各点極限と、分布収束の根拠を明記する。密度の点ごとの収束だけでは常に分布収束が自動的に従うわけではない。
- **変数変換やパラメータの特殊化**：各段階の密度・質量関数が**厳密に一致**することを示し、極限と混同しない。
