## 分布による仮定の違い

- **多項分布**：離散ベクトル。各ベクトルの合計$N$が固定なので、共分散行列は通常ランク$k-1$の**特異行列**。
- **正定値の多変量正規分布**：連続ベクトルで$\Sigma\succ0$。正規密度・行列逆行列・Fisher情報の導出には正定値性が必要。
- **多項分布の標本数と試行回数**：iidベクトルの標本数を$n$、**1ベクトル内の試行回数**を$N$と区別する。
- **正規分布の標本数と次元**：iidベクトルの標本数を$n$、次元を$d$と区別する。
- **MLEと不偏性**：正規の平均MLE$\bar{\boldsymbol X}$は不偏でCR等号を満たす。一方、$\hat\Sigma$（分母$n$）は平均未知では偏りがあり、通常の不偏Cramér–Rao不等式をそのまま適用できない。
- **順序統計量の記号**：スカラー標本では$X_{(1)}\le\cdots\le X_{(n)}$。ベクトル値の標本には一般に自然な全順序はない。
