# Internal link rules

> [!note] 問題ノートのリンクは `concepts` Property
> 問題ノート（`01_`〜`05_`）の本文（`## 問題の要約`・`## 答案`）に `[[...]]` は書かない。`## 関連` 節も作らない。
> 概念ノートへのリンクはfrontmatterの `concepts` にだけ書く（`.agents/rules/frontmatter.md` §4）。
> 概念ノート側は、その概念を使う問題を `.base` の埋め込みで一覧する。手書きの問題リストは作らない。

## Add links when useful

数学的な依存・関連が明確な場合に `[[内部リンク]]` を付ける。

例:

- 最尤推定 → [[尤度関数]], [[対数尤度]], [[スコア関数]]
- 順序統計量 → [[最大値分布]], [[最小値分布]]
- Itô積分 → [[Wiener過程]], [[Itôの公式]]

## Before creating a link target

1. Vault内を同義語・日本語/英語表記で検索する。
2. 既存ノートがあればそれへリンクする。
3. 既存ノートがなく、独立ノートとして継続的価値がある場合のみ新規作成を検討する。

同じ概念について次のような重複を作らない。

```text
最尤推定.md
MLE.md
Maximum Likelihood.md
```

必要ならaliasを使う。

## Placement

問題ノート: `concepts` に `"[[概念ノート名]]"` を2〜5個。存在する概念ノートだけを指す。

```yaml
tags:
  - 変数変換
concepts:
  - "[[変数変換]]"
  - "[[期待値]]"
```

概念ノート（`08_数理統計学用語深堀/` の分野別サブフォルダ。`note-routing.md`）: 本文の `## 関連` 節に、関連概念ノートへの `[[...]]` を書いてよい。
概念ノートには、その概念を `concepts` に持つ問題を一覧する `.base` を埋め込む。

```markdown
## 使われる問題

![[概念別問題一覧.base]]
```

（`.base` 側で `concepts.contains(this.file)` のように現在のノートで絞り込む。）
