## 08 概念ノートのサブフォルダ

`08_数理統計学/` の概念ノートは、`00_学習管理/MOC/数理統計学.md` の「概念ノート」の見出しと同じ分野別フォルダに置く。

- `確率・期待値/`: 期待値、分散、積率母関数、変数変換など（ガンマ関数・不等式・ヤコビアンなどの数学的道具は `06_数学/`）
- `確率分布/`: 個別の1変量確率分布。カイ二乗・t・F分布もここに置く（ハザード関数は `生存解析/`、多項分布・多変量正規分布は `多次元確率変数/`）
- `多次元確率変数/`: 独立性、共分散、条件付き分布・期待値など
- `標本分布・漸近論/`: 標本平均、順序統計量、正規標本の t・カイ二乗・F 統計量、収束、中心極限定理、大数の法則、デルタ法
- `推定/`: 点推定、最尤推定量、フィッシャー情報量など
- `検定/`: 尤度比検定、ワルド検定、スコア検定、t検定、カイ2乗検定、マン・ホイットニー検定、ログランク検定、同等性検定、多重比較など
- `分散分析/`: 一元・二元配置、コクランの定理、共分散分析、線形対比、閉手順
- `生存解析/`: ハザード関数、カプラン・マイヤー、Cox、打ち切り、競合リスク
- `ノンパラメトリック統計/`: 符号検定、符号付き順位検定、ウィルコクソン順位和検定、並び替え検定、感度・特異度とROC・AUC
- `一般化線形回帰/`: 単・重回帰、一般化線形モデル、ロジスティック回帰、ポアソン回帰、負の二項回帰、ガンマ回帰
- `ベイズ統計/`: ベイズの定理、ベイズ推定の基本、損失関数とベイズ推定、共役事前分布
- `多変量解析/`: 主成分分析、判別分析、因子分析、クラスター分析

### フォルダと `stats-category` の対応

`stats-category` は `.agents/references/taxonomy.md` の語彙（教科書の章分類）で付ける。フォルダは学習用の分野分けで、両者は完全には一致しない。置き場所はフォルダ、frontmatterは次の表で決める。

| フォルダ | stats-category | 備考 |
|---|---|---|
| `確率・期待値/` | `確率` | |
| `06_数学/`（参考） | 内容に最も近い語 | ガンマ・ベータ・ディガンマ関数は `確率分布`、ヤコビアン・極座標変換は `多次元確率変数`、射影行列と二次形式は `分散分析`（教科書の章に合わせる） |
| `確率分布/` | `確率分布` | |
| `多次元確率変数/` | `多次元確率変数` | |
| `標本分布・漸近論/` | `標本分布` | |
| `推定/` | `推定` | |
| `検定/` | `検定` | |
| `分散分析/` | `分散分析` | |
| `生存解析/` | `生存解析` | |
| `ノンパラメトリック統計/` | `ノンパラメトリック` | |
| `一般化線形回帰/` | `回帰` | |
| `ベイズ統計/` | `ベイズ統計` | |
| `多変量解析/` | `多変量解析` | |

- ノート名はVault全体で一意にする。リンクは `[[ノート名]]` だけで解決されるので、フォルダ名を書かない。
- 新しい概念ノートを作るときは、置き場所を決めて同じフォルダ内に作り、MOCの同じ見出しにも追記する。
- 移動するときは、ノート名を変えない（`concepts` のリンクが壊れるため）。

### 分野索引（README）と学習マップ

- 各分野フォルダ（`06_数学/`, `07_計算機統計学/`, `08_数理統計学/<分野>/`）の `README.md` は、その分野の読む順・導出の索引である。概念ノートではないので `## 使われる問題` の埋め込みは不要。
- `README` はVault内で同名が複数あるため、リンクはパス付きで書く（例: `[[08_数理統計学/確率分布/README|確率分布 README]]`）。
- `08_数理統計学/` 直下には分野横断の学習マップ・総復習ノートだけを置く。
- 新しい README・学習マップを作ったら `00_学習管理/MOC/数理統計学.md` の「学習マップ・索引」に追記する。
