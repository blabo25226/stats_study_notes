# Organize Vault

1. 変更前にVault全体を検索する。
2. 重複候補、孤立ノート、Propertiesの表記揺れを列挙する。
3. 数学的内容は変更せず、構造上必要な最小変更だけ行う。
4. 既存MOCへ適切なリンクを追加する。
5. 新規概念ノートを乱造しない。
6. 大量移動・大量改名はユーザーが明示した場合のみ行う。
7. 作業内容は必要に応じて `daily_report.md` のルールへ引き継ぐ。
