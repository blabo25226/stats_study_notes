# Create Concept Note

## Before creation

- 日本語名、英語名、略称でVault検索する。
- 既存ノートがあれば新規作成せず、必要なら既存ノートを改善する。

## Routing

内容に応じて `06`, `08`, `10`, `13`, `14`, `15` など適切なフォルダへ置く。

## Suggested structure

```markdown
---
test-category:
stats-category:
difficulty: 中
---

# 概念名

## 定義

## 直観

## 重要な式

## 例

## 関連

- [[関連概念]]
```

採点対象でない概念ノートに `status` を付けない。
