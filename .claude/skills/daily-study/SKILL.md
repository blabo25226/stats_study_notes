# Daily Study

保存先:

```text
00_学習管理/Daily/YYYY-MM-DD.md
```

## Build today's plan

1. `next-review <= today` の問題を確認する。
2. 不正解・部分的なミスありを優先候補として提示する。
3. ユーザーが現在進めている章や分野が明確なら加味する。
4. 過剰な問題数を勝手に割り当てない。

## Update after study

- 解いた問題へのリンク
- 採点結果
- 今日理解した概念
- 疑問点
- 次回

を追記する。

`daily_report.md` はこのSkillの出力先ではない。
